# 사주 서비스 — 대운으로 보는 내 인생 흐름

[English](README.md) · **한국어**

생년월일·출생 시각·출생 도시로 **사주**를 계산하고, 내 삶을 **10년 단위 대운**의 흐름(과거 → 현재 → 미래)으로 보여주는 웹 서비스입니다. AI 에이전트와 함께 기능 명세와 자동 테스트를 하나씩 쌓아 가며 만들었습니다.

**[서비스 바로가기](https://saju-service-steel.vercel.app/)** · 현재 버전: **v0.3.1** · [변경 이력](CHANGELOG.md)

## 할 수 있는 것

- **사주 계산**: 양력·음력(윤달 포함) 생일, 출생 시각, 출생 도시를 넣습니다. 도시의 시간대와 경도를 계산에 반영합니다.
- **인생 흐름 보기**: 나만의 대운을 시간 순서로 보여주고, 지금 지나고 있는 대운을 표시합니다. 인생 그래프와 '인생의 사계절' 설명도 있습니다.
- **해석 읽기**: 규칙 기반 해석이 브라우저에서 바로 나옵니다. 동의하면 AI(Gemini) 해석으로 더 깊은 요약을 볼 수 있습니다.
- **오늘의 운세**: 한국 시간 오전 9시에 새로 바뀌는 짧은 하루 운세입니다.
- **저장과 공유**: 이 브라우저에 결과 하나를 저장하거나, Google로 로그인해 내 계정에만 저장할 수 있습니다. 공유 카드에는 한 줄 메시지만 담기고 출생 정보는 들어가지 않습니다.

해석은 스스로를 돌아보기 위한 참고 자료이며, 앞으로 일어날 일을 예언하거나 보장하지 않습니다.

## 개인정보

- 규칙 기반 해석은 브라우저 안에서 계산하며 아무것도 보내지 않습니다.
- AI 해석은 동의한 경우에만 실행합니다. Gemini에는 계산된 사주 값만 보내고, 실제 생년월일·시각·장소는 보내지 않습니다.
- 계정 저장은 Supabase의 행 단위 보안을 씁니다. 각자 자기 기록만 읽고 지울 수 있습니다.

## 직접 실행하기

Node.js 22.9 이상이 필요합니다.

```sh
npm ci
npm run dev
```

터미널에 나온 주소를 브라우저에서 엽니다.

선택 설정은 `.env.local`에 넣습니다(`.env.example` 참고). 설정이 없어도 사주 계산과 규칙 기반 해석은 동작하고, AI 해석은 "사용할 수 없음"으로 나오며 로그인은 꺼집니다.

| 변수 | 쓰임 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Google 로그인과 계정 저장 |
| `GEMINI_API_KEY` | AI 해석 (서버에서만 사용) |
| `CRON_SECRET` | 매일 오전 9시 작업 보호 |

검사:

```sh
npm run check   # 타입 검사 + 전체 자동 테스트
npm run build   # 배포용 빌드
```

## 사용 기술

Next.js 16, React 19, TypeScript, 달력 계산용 `lunar-javascript`, Supabase(로그인·저장), Google Gemini, Vercel(배포·매일 작업).

## 폴더 구성

```text
├── app/                 화면, 그리고 app/api의 API 경로
├── lib/saju/            사주 계산과 해석 규칙
├── lib/account/         계정 저장
├── supabase/migrations/ 데이터베이스 표와 접근 규칙
├── tests/               자동 테스트
├── docs/
│   ├── PRD.md           제품 목표와 범위
│   ├── specs/           기능별 명세와 검증 결과
│   └── status.md        완료·검증된 기능 목록
└── AGENTS.md            AI 에이전트 작업 원칙
```

기능마다 `docs/specs/`에 명세를 먼저 쓰고, 만들고 테스트한 뒤, 검증까지 끝난 것만 `docs/status.md`에 체크합니다. 만들었지만 아직 사람이 화면에서 확인하지 않은 기능도 있으며, 어떤 것인지는 `docs/status.md`에 나와 있습니다.
