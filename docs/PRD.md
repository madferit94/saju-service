# 📋 기획서 (PRD): 개인 대운으로 보는 인생 흐름

> 이 문서는 무엇을 왜 만들지 정한 기획서입니다. 아직 구현 지시서나 계산 정확도 검증 결과는 아닙니다.

작성일: 2026-09-23
작성자: 참가자

## 1. 풀고자 하는 문제

- **현재 방식:** 사주가 궁금할 때 가끔 찾아본다.
- **불편한 점:** 자신의 과거와 앞으로의 삶을 한 흐름으로 이해하고, 미래의 선택을 생각할 때 참고할 만한 개인화된 설명이 필요하다.
- **원하는 변화:** 자신의 사주에 따른 대운을 과거 → 현재 → 미래 순서로 보고, 과거의 특징은 실제 경험과 비교하며 미래의 흐름은 판단 자료로 활용한다. 진로·관계·돈은 삶 전반의 하위 주제로 다룬다.

## 2. 사용자

- **누가:** 사주를 가끔 찾아보는 사람.
- **언제:** 지난 삶을 돌아보거나 앞으로의 삶과 선택을 생각할 때.
- **어디서:** 브라우저에서 사용하고, 저장 링크로 다른 기기에서도 다시 연다.
- **가장 중요한 경험:** 이용자별 대운을 기준으로 인생 흐름을 시간순으로 읽는 것. 대운은 사주에서 삶의 흐름을 약 10년 단위로 살펴보는 개념이다.

## 3. 입력 자료

- **기본 입력:** 본인의 양력 또는 음력 생년월일, 음력의 평달·윤달 여부, 출생 시각, 출생 국가와 도시, 대운 계산 기준. 1990년 이후 출생과 출생 시각을 아는 경우를 지원한다. 도시의 시간대와 경도를 계산에 반영한다. 윤달 여부를 모를 때 같은 연·월에 윤달 날짜가 실제로 있으면 두 원국과 변환된 양력 날짜를 비교해 고르게 한다.
- **궁합 입력:** 비교할 상대의 출생 정보가 필요하다. 필수 항목과 계산 기준은 기능 명세에서 정한다.
- **개인정보:** 출생 정보와 해석 결과는 개인 정보로 취급한다. Gemini 전송 전 이용자 동의를 받고, 모델에는 계산된 사주·오행·귀인·시기별 운 정보만 전달한다. 원래 출생 정보는 Gemini에 보내지 않는다. 비로그인 결과는 브라우저 `localStorage`에 한 건 저장한다. Google 로그인 후 이용자가 ‘계정에 저장’을 누르면 출생 입력·계산·해석 전체를 Supabase에 본인 전용 기록으로 저장한다. 서버 결과를 열 때는 기기에 자동 복사하지 않으며 로그아웃 시 화면에서 지운다.
- **아직 정하지 않은 것:** 출생 시각을 모르는 경우, 1990년 이전 출생, 목록에 없는 도시의 입력 방법, 저장 기간과 삭제 정책.

## 4. 핵심 기능: 첫 버전

1. 출생 정보와 출생 국가·도시를 입력하고 지역의 시간대와 경도를 적용한 사주 계산 결과를 확인한다.
2. 이용자별 대운을 계산해 과거·현재·미래 구간을 시간순으로 보여준다. 현재 구간을 쉽게 찾을 수 있게 표시한다.
3. 계산된 사주·대운·오행·여러 귀인을 바탕으로 결과 화면에서 각 구간의 삶 전반을 설명한다. 진로·관계·돈은 하위 항목으로 제시한다. 오랜 경력의 역술가처럼 차분하고 구체적인 문체를 지향하되, 실제 경력을 가진 사람이라고 주장하지 않는다. 강점과 주의할 점을 함께 말한다. 과거의 실제 사건을 맞혔다고 주장하지 않고, 이용자가 자신의 경험과 비교하도록 돕는다.
4. 결과를 저장하고, 링크를 가진 사람은 회원가입이나 비밀번호 없이 다른 기기에서 다시 열 수 있게 한다. 링크를 공유하면 상대도 출생 정보와 결과를 볼 수 있음을 저장 전에 알린다.
5. 두 사람의 사주를 비교하는 궁합 보기를 제공한다. 구체적인 비교 항목과 표현 방식은 기능 명세에서 정한다.

- **해석 방식:** 결과 화면에서 먼저 로컬 규칙 기반 해석을 바로 볼 수 있다. 이용자가 원하면 별도 동의 후 Gemini `gemini-3.5-flash-lite`로 더 깊은 종합 해석을 생성한다. 한문 간지에는 한글 독음과 천간·지지의 오행 관계 풀이를 함께 제공한다. 로컬 해석은 브라우저에서 계산해 외부로 보내지 않는다. 두 방식 모두 대운마다 강점·부담·현실 조언을 설명하고 과거 경험과 비교하도록 돕는다. 단편적인 귀인 판정이나 오행 개수만으로 운명을 단정하지 않는다.
- **사람이 확인할 것:** 과거 해석이 자신의 실제 경험과 맞는지, 미래 해석을 선택의 참고 자료로 쓸지. 미래 사건이나 결과를 확정적으로 보장하지 않는다.

## 5. 결과와 완료 조건

- **결과물:** 기존 `day09/` 웹 서비스에 개인별 대운 흐름, 오행·귀인 근거, 화면 내 해석, 저장 링크, 궁합 화면이 동작하는 첫 버전.
- **정상 입력:** 출생 정보와 도시를 넣으면 본인의 대운 구간이 시간순으로 나타나고, 오행·귀인 근거, 과거·현재·미래 해석과 진로·관계·돈 하위 항목을 볼 수 있다. 저장 링크를 다른 기기에서 열면 같은 결과가 나온다.
- **입력 오류:** 필수 정보가 빠졌거나 날짜가 유효하지 않으면 어떤 입력을 고쳐야 하는지 알려준다.
- **서비스 오류:** 계산이나 저장에 실패하면 성공한 것처럼 꾸미지 않고 실패와 재시도 방법을 보여준다.
- **궁합:** 두 사람의 유효한 출생 정보를 넣으면 비교 결과가 나타난다. 정확한 항목과 완료 기준은 기능 명세에서 확정한다.

## 7. 만드는 방식과 공유 방법

- **방식:** 기존 Next.js 웹 서비스(`day09/`)를 확장한다. 저장 링크를 다른 기기에서 열려면 서버 측 저장소와 인터넷에서 접속할 주소가 필요하다.
- **공유:** 완성 후 배포 주소를 통해 접근한다. 배포 장소, 저장소와 접근 권한은 구현 전에 정한다.
- **링크 접근:** 링크를 가진 누구나 결과를 열 수 있다. 추측하기 어려운 링크를 사용하고, 링크 노출·삭제·보관 기간을 구현 전에 구체화한다.

## 8. 현재 구현 범위

- 기획서 작성 후 참가자 요청에 따라 개인별 대운, 오행·귀인, 출생 국가·도시의 시간대·경도 반영을 구현했다. Gemini 해석과 로컬 규칙 해석을 모두 제공하며, 결과를 브라우저에 저장한다.
- 1990~2100년 음력 생일과 윤달 선택을 지원한다. 윤달 여부가 모호한 날짜는 임의로 하나를 고르지 않고 두 결과를 비교하게 한다.
- 저장 링크와 궁합은 첫 버전의 목표에 남겨두고 차례로 구현한다.
- 평생운·대운·세운·절입 월운을 원국의 십성·지장간·합충과 종합한다. 현재 해석과 다른 버전·연도로 생성된 과거 해석은 재생성 안내를 표시한다.
- 신강신약은 계절·지장간·뿌리·생조와 소모를 공개한 서비스 비교 규칙으로 살펴본다. 격국은 월령·투간 후보, 용신은 억부와 조후 관점을 나눠 설명한다. 경계와 특수격 가능성은 자동 확정하지 않는다(Spec 013).
- 원국·강약·격국/용신·평생·일/배움·돈/자원·관계·실천의 8장 상담을 추가한다. 각 절에 근거, 반대 조건, 가정 예시, 실제 경험 질문과 실천을 포함하며 장별 생성·부분 저장·멈추기·재개를 제공한다. 실제 경력이나 상담시간을 사칭하지 않는다.
- Google 로그인, 본인 결과 저장·목록·열기·삭제를 추가한다(Spec 011/012). 로그인 기반 보관함은 공개 저장 링크와 구분하며, 이번 계정 저장본은 링크만으로 타인에게 공개되지 않는다.
- 실습 종료 시각과 구현에 쓸 수 있는 시간은 확인되지 않았다. 이후 단계의 순서와 범위는 시작 전에 정한다.

## 9. 첫 구현 목표 (다음 단계의 30분 예산)
