# 출생 입력 한 번으로 Gemini 종합 해석 만들기

## 요청
- 사주표 아래의 긴 전송 설명·체크박스·추가 생성 버튼을 없앤다.
- 출생 정보를 제출할 때 Gemini 종합 해석까지 자동으로 만든다. 별도의 두 번째 버튼을 요구하지 않는다.

## 구현 기준
- 입력 화면에서 한 번 누를 버튼에 Google Gemini로 계산된 사주 자료가 전송됨을 짧고 분명하게 알린다. AI 없이 로컬 사주만 보는 한 번 누르기 선택지도 제공한다.
- 로컬 계산 결과는 즉시 보여 주고, Gemini 해석은 준비되면 같은 결과에 덧붙인다. 서버에는 기존과 같이 `consent: true` 요청을 보내고, 원래 생년월일·출생 시각·출생지는 Gemini 프롬프트에 포함하지 않는다.
- 윤달 두 후보가 나오는 경우 먼저 실제 생일 후보를 고른 뒤 선택한 후보 하나에 대해서만 Gemini를 요청한다.
- 저장된 결과를 열거나 화면을 전환하는 것만으로 Gemini를 새로 호출하지 않는다. 실패 시 로컬 결과는 남기고 오류와 재시도 수단을 보여 준다.
- 기존 저장 자료, Gemini 응답 형식과 계정 저장 규칙을 유지한다.

## 검증
- 독립 서브에이전트가 Gemini 선택·로컬 선택·윤달 선택·저장본 열기·실패 재시도의 호출 횟수와 전송 동작을 검사한다.
- 타입 검사, 전체 테스트, 배포용 빌드, 로컬 화면의 성공·실패·재시도 표시를 확인한다.

## 상태
- 구현 완료. 출생 입력 화면의 짧은 전송 안내와 두 가지 제출 버튼, 로컬 결과 선표시, Gemini 자동 요청, 실패 시 재시도를 적용함.
- 독립 테스트에서 Gemini 선택·AI 없이 보기·윤달 후보·저장본 열기·실패 재시도의 요청 횟수를 확인함. 전체 222개 테스트, 타입 검사, 배포용 빌드 통과.
- 로컬 입력 화면과 사주표 화면의 변경된 구성을 브라우저에서 확인함. 실제 출생 정보로 Gemini 생성·실패·재시도 화면을 참가자가 직접 확인하기 전이며 GitHub·Vercel에는 반영하지 않음.
