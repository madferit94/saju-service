# 021 매일 오전 9시 오늘의 운세

## 목표

모든 방문자가 출생 정보를 입력해 계산한 사주 결과에서 한국 시간 기준 오늘의 짧은 운세를 읽는다. AI 전송이나 로그인은 필요하지 않다.

## 동작

1. 한국 시간 오전 9시부터 그 날짜의 오늘 운세를 보여준다. 오전 9시 전에는 준비 시각을 알리고 오늘 풀이를 미리 표시하지 않는다.
2. Vercel Cron은 매일 00:00 UTC(한국 시간 09:00)에 보호된 GET 경로를 호출해 날짜별 공통 일진 자료를 서버 캐시에 미리 만든다. `CRON_SECRET`이 없거나 인증 값이 다르면 401을 반환한다.
3. 방문자가 오전 9시 이후 처음 접속했는데 예약 호출이 늦거나 누락되더라도, 공개 읽기 경로에서 같은 날짜 자료를 계산한다. 날짜를 캐시 키로 사용하므로 중복 호출은 같은 날 자료를 만든다.
4. 개인 풀이와 출생 정보는 브라우저에서만 결합한다. 서버의 오늘 자료 경로에는 출생 정보를 보내지 않는다. 기존 계정 저장 결과도 바꾸지 않는다.
5. 일진의 천간·지지와 본인 일간의 십성, 원국과의 합·충 일부, 현재 대운을 근거로 활용점·부담·행동을 읽는다. 건강·합격·수익·사건을 확정하거나 행운 점수를 만들지 않는다.
6. 화면을 계속 열어 두었다면 다음 한국 시간 오전 9시 이후 새 자료를 읽는다. 실패 시 실패 안내와 다시 불러오기 버튼을 제공한다.

## 검증

- 한국 시간 08:59 / 09:00 경계, 날짜 변경, 다른 사주에 다른 근거가 표시되는지 확인한다.
- Cron 인증 누락·오류 시 401, 정상 호출 시 날짜와 간지 응답을 확인한다.
- 관련 테스트, 타입 검사, 전체 테스트, 배포용 빌드를 실행한다.
- 실제 Vercel 예약 호출은 프로덕션 배포 후 Vercel Cron Jobs 로그에서 확인한다. 무료 요금제에서는 지정한 1시간 안에 호출될 수 있으며 자동 재시도는 없다.

## 확인 상태

- 한국 시간 08:59/09:00, 날짜 오류, 개인별 근거 차이, 공개 경로, 예약 경로 인증·시간, 예약 설정을 확인하는 신규 테스트 6개 통과.
- 전체 테스트 170개, 타입 검사, 배포용 빌드 통과. 로컬 공개 경로 HTTP 200과 인증 없는 예약 경로 401 확인. 브라우저에서 기존 저장 결과 아래 오늘 운세 카드가 표시되는 것을 확인.
- Vercel 프로덕션의 `CRON_SECRET` 설정, 실제 예약 호출, 참가자 화면 확인은 아직 남음. 그래서 `docs/status.md`는 미완료 상태로 유지.
