# 평생 흐름과 대운·세운·월운 종합 해석

## 목적
사주가 다른 사람에게도 그대로 붙일 수 있는 일반적인 조언을 줄이고, 개인 원국과 시기별 근거를 연결해 선택에 도움이 되는 해석을 제공한다.

## 범위
후속 Spec 013에서 강약 비교·격국/용신 후보와 상담형 해석 범위를 확장했다. 아래 미판정 범위는 이 문서 최초 구현 당시의 기준이다.
- 십성, 지장간, 천간합·지지육합·충을 계산한다. 합화·격국·용신·신강신약은 판정하지 않는다.
- 평생 흐름은 실제 대운과 연령 구간(초년·청년·중년·후반)의 교집합으로 구성한다. 수명 예측이 아니다.
- 선택 연도의 세운과 12절입 월운을 정확한 절기 시각으로 구분하고 원국·해당 대운과 연결한다. 월운은 양력 1일에 바뀌지 않는다.
- 각 해석에 근거, 활용할 상황, 부딪힐 부담, 구체적 행동과 확인 질문을 표시한다. 시기의 연령에 맞지 않는 직장·투자 조언을 어린 시절에 붙이지 않는다.
- 로컬 계산 해석과 AI 심층 해석을 개선한다. 결과 카드의 'Gemini 참고 해석' 문구는 제거하고, AI 생성 사실 및 Google 전송 내용은 생성 동의 영역에서 설명한다.
- Gemini gemini-3.5-flash-lite에 계산된 자료만 전송한다. 종합·평생·세운·12월운 필드를 요구하고 누락된 응답은 거부한다.
- 예전 저장 해석을 보존하면서 이전 버전임을 알리고 재생성 버튼을 제공한다. 실패 시 기존 해석을 유지한다.

## 검증
십성 음양 관계, 합충, 다른 원국의 다른 해석, 절기 경계, 연령 구간, 과거 저장 결과 호환성과 재생성·실패 경로를 검증한다. 실 API 검증은 가상 출생 정보로만 실행한다. 실제 응답 품질을 확인하지 못하면 그 범위를 명시한다.

계산 참고: https://6tail.cn/calendar/api.html 및 설치된 lunar-javascript 1.7.7 소스.

## 상태
구현·검증 완료(참가자 확인 전).
- 십성·지장간·합충, 절입 시각, 연령별 흐름, 과거 저장 호환성 및 AI 구조·근거 검사를 자동 검증했다.
- 가상 출생 자료로 실제 Gemini 응답 HTTP 200, 평생 4단계·세운·12개월·11개 대운 해석을 확인했다. 최초 응답의 대운 0번 누락과 월운/대운 혼동을 발견해 동적 응답 형식, 계산값 대조 및 1회 보정 재시도를 추가했다.
- 전체 검사 74개 통과(이후 계정 저장 기능 포함 90개), 최종 빌드 통과. 브라우저에서 평생운/연운/12월운과 이전 해석 재생성 안내를 확인했다.
- 특정 입력의 해석 품질을 확인한 것이며 모든 출생 사례에 대한 전문 감수나 미래 예측 정확도를 검증한 것은 아니다.
