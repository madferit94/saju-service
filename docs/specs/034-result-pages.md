# 사주 결과 항목별 화면

## 요청
- 긴 결과를 한 화면에 이어 붙이지 않고, 메뉴에서 항목을 고르면 그 항목의 화면만 보인다.
- 기존 8개 메뉴: 사주표, 오늘의 운세, 오행·십성, 균형·도움, 인생 그래프, 인생 4계절, 운의 흐름, 생활 운.

## 구현 기준
- 항목마다 `?view=` 주소가 달라지고 브라우저 뒤로·앞으로 가기로 이전 항목에 돌아간다. 화면 전환 중 계산 결과와 계정에서 연 결과는 유지한다.
- 출생 정보 입력과 계정 보관함은 별도 `?view=input` 화면으로 둔다. 새 계산이나 보관함의 결과를 열면 사주표 화면으로 간다.
- 메뉴는 모든 결과 화면의 위에 있고 현재 항목을 표시한다. 한 번에 선택 항목의 본문만 렌더링한다.
- 사주표에는 도령 한줄평·공유 카드·네 기둥·귀인·타고난 네 기둥 풀이·선택형 AI 종합 해석을 둔다. 오행·십성은 독립 화면으로 옮긴다.
- 운의 흐름에는 대운·세운·월운과 대운 시간표를 두고, 생활 주제별 운은 독립 화면으로 옮긴다.
- 이전 `#` 주소는 대응하는 화면을 열 수 있게 한다. 개인 출생 정보나 계산 결과를 주소에 넣지 않는다.
- 저장 형식, 사주 계산 규칙, 공유 기능의 개인정보 범위는 바꾸지 않는다.

## 검증
- 8개 항목이 각각 단독으로 나타나고 메뉴의 현재 표시가 맞는지 확인한다.
- 새 계산, 브라우저 저장본, 계정 저장본, 뒤로 가기와 기존 `#` 주소가 올바른 화면으로 이어지는지 확인한다.
- 전체 테스트와 빌드를 통과하고 모바일 화면에서 메뉴와 본문을 확인한다.
