# 조합별 해석과 시기 연결·내용 검증

## 요구와 구현 순서
1. 같은 십성을 다섯 생활 주제로 묶되 원국의 생조·소모 조건에 따라 기회·부담·실천을 구분한다. 민감/특수 원국은 강약 방향을 확정하지 않는다. 실제 월령·뿌리·조후 근거와 규칙 ID를 함께 보관한다.
2. 원국을 바탕으로 대운→세운→월운의 주제가 이어지는지, 달라지는지를 설명한다. 입춘 전 월운에는 해당 월의 실제 세운을 사용한다. 종합 해석과 분야별 AI 풀이가 같은 핵심 해석을 사용한다. 미성년·후반기 보호와 계절/그래프의 분리를 유지한다.
3. Gemini에는 계산된 해석 계획을 주고 종합·연운의 근거 선택을 구조화해 검증한다. 간지 층위 검증을 연운·대운으로 확대하고, 대표적인 확정 예언과 반대 강약 단정을 차단한다. 잘못된 출력은 기존 1회 수정 후 오류로 처리하며 로컬/요약을 유지한다.

## 출력과 실패 조건
- 모델이 강약이나 시기 간지를 새로 계산하지 않는다. 근거 ID와 규칙 ID 검증은 설명 전체의 의미가 참임을 증명하지 않으며 감수 필요 범위를 기록한다.
- 이전 저장 형식은 읽을 수 있다. 새 전체 생성 응답만 새 근거 필드를 요구하며 프롬프트 버전으로 세션 캐시를 분리한다.
- 근거 접기 창을 추가하지 않는다. 검증용 필드는 내부 자료로 다룬다.
- 없는 근거/규칙, 누락된 근거, 틀린 시기 명칭, 명백한 단정 표현을 실패로 처리한다.
- 현재 나이를 명시하며 미성년의 종합·올해·월별·직업·돈·관계 풀이에 성인 직장·수입·투자 조언이 나오면 재작성을 요구한다. 평생운/대운의 미래 성인 구간과 이전 저장본 호환은 유지한다.

## 검증
- 독립 담당자가 다양한 가상 원국·같은 운 대조, 강약 경계, 시기 전환, 연령 보호, 조작된 AI 출력과 정상 문장의 오탐을 테스트한다.
- 타입 검사·전체 테스트·빌드와 실제 가상 입력 AI 응답 및 로컬 화면을 확인한다. 예측 정확도 향상을 주장하지 않는다.

- 다섯 주제 × 네 조건(생조 필요/생조 우세/중간/판정 유보)의 20개 조합을 구현했다. 뿌리·조후는 계산 근거와 설명 조건으로 제공하며 독립적인 전통 격국 판정이나 수치 가산은 추가하지 않았다.
- 가상 성인(2000-06-15 12:00 서울, 남성식, 2026년): 요약 HTTP 200 약 2.657초, 전체 HTTP 200 약 19.655초. 종합/연운 모두 `output:support-needed`와 필수 계산 근거를 반환했으며 12개월·11개 대운 형식 검증 통과.
- 가상 미성년(2018-03-12 10:30 서울, 여성식, 2026년): 요약 성공 후 전체 응답이 새 근거 검사에서 거절됐다. 별도 가상 진단에서 연운이 접두사 없는 근거 ID를 사용하고 성인 수입 표현을 생성하는 현상을 확인했다.
- 이후 규칙/근거를 응답 스키마 enum으로 제한하고, 현재 나이를 프롬프트에 명시했으며 미성년 현재 조언 검사를 추가했다. 같은 화면의 재시도에서 HTTP 200 약 13.4초. 학교·배움·친구·용돈 중심의 실제 화면을 확인했다. 실패 중에도 요약과 로컬 결과가 유지됐다.
- 실측은 가상 사례 관측이며 운영 성능 개선률이나 예측 정확도를 뜻하지 않는다. 근거 메타데이터와 대표 표현 검사는 모든 자연어 의미·사건 진실성·명리 해석의 정답을 보장하지 않는다. 전문가 감수와 더 넓은 사례 평가는 후속 범위다.
