# 005 세계 도시 한글 검색

## 목적

국가를 먼저 선택한 뒤 해외 도시도 한글 이름으로 검색하고 정확한 도시를 고를 수 있게 한다.

## 범위

- 기존 도시·시간대·경도 자료는 유지한다. 한글 별칭은 GeoNames의 도시 이름 자료에서 추출해 로컬 파일로 제공한다.
- 국가 코드와 좌표를 함께 확인해 GeoNames의 별칭을 기존 도시 자료에 연결한다. 이름이 같은 도시는 지역·시간대 정보를 보여주어 구분한다.
- 한글 별칭이 없는 도시는 영문 이름 검색을 계속 지원한다. 검색되지 않는 이름을 임의로 가까운 도시에 연결하지 않는다.
- 도시 검색은 앱 서버 안에서 처리하고 외부 지명 검색 서비스로 보내지 않는다.
- 화면과 문서에 GeoNames 출처 및 CC BY 4.0 표기를 남긴다.

## 자료 출처

- GeoNames `cities5000.zip`: https://download.geonames.org/export/dump/cities5000.zip
- 형식·라이선스: https://download.geonames.org/export/dump/readme.txt

## 완료 조건

1. 한국 도시와 미국·일본·유럽 등 대표 해외 도시의 한글 검색 결과가 나온다.
2. 국가를 다르게 선택하면 같은 한글 이름이 다른 국가의 도시로 연결되지 않는다.
3. 영문 검색도 유지된다.
4. 검색 결과에 지역과 시간대가 표시되고, 선택 후 기존 사주 계산이 동작한다.
5. 자동 검사와 실제 화면을 확인한다.

## 검증 결과

- GeoNames 한글 별칭 3,499개를 기존 도시 3,367개에 연결했다. 한글 별칭이 없는 도시는 기존 영문 검색을 사용한다.
- `npm run check`: 타입 검사 및 테스트 36개 통과. 한국·미국·일본·프랑스·영국·호주의 한글 도시 검색, 영문 검색 유지, 국가별 검색 범위, 부분 한글 검색을 확인했다.
- `npm run build`: 통과.
- 브라우저에서 미국 `뉴욕`, 일본 `도쿄` 검색 결과와 지역·시간대 표시를 확인했다. 참가자 확인 전.
- 사용자 제보로 확인한 누락: 기본 도시 자료에 안양이 없어 `안양` 검색 결과가 없었다. 안양시청 대표 좌표(경도 126.95687°)를 사용한 보완 항목을 추가해 `안양`·`anyang` 검색, 대한민국·경기도·Asia/Seoul 반환을 자동 검사와 실행 중인 API에서 확인했다.
- 화면에서 이전의 빈 검색 결과가 남을 수 있어 도시 검색 요청과 응답 모두 캐시하지 않도록 변경하고 응답 헤더 테스트를 추가했다.
