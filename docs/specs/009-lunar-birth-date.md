# 음력 생일과 윤달 입력

## 목표

사주를 계산할 때 양력과 음력을 구분하고, 음력은 평달·윤달·모름을 선택할 수 있게 한다. 입력 날짜를 실제 양력 출생 날짜로 변환한 다음 기존 출생 도시 시간대 보정, 원국과 대운 계산에 사용한다.

## 사용자 흐름

1. 날짜 기준에서 양력 또는 음력을 고른다.
2. 양력은 기존 날짜 입력을 사용한다. 음력은 연·월·일과 윤달 여부를 입력한다.
3. 음력의 ‘모름’은 입력한 연도에 해당 달의 윤달이 있는지 확인한다.
4. 윤달이 없으면 평달 하나로 계산하고 그 판단을 화면에 알린다.
5. 평달과 윤달이 모두 가능하면 각각의 양력 환산 날짜, 네 기둥, 첫 대운 시작일을 함께 보여준다. 이용자가 지난 경험과 비교해 한쪽을 고른 뒤 상세 결과와 저장을 진행한다.
6. 평달·윤달을 명시했지만 그 날짜가 달력상 존재하지 않으면 계산하지 않고 입력 오류를 설명한다.

## 검증 및 계산 기준

- 음력 출생 연도는 1990~2100년을 지원한다. 양력 환산 결과도 1990년 이후여야 한다.
- 음력 월은 1~12, 일은 1~30 범위이며 해당 월의 실제 일수는 변환 라이브러리로 확인한다.
- 양력·음력 변환은 기존 의존성 `lunar-javascript@1.7.7`을 사용한다.
- 모든 차트, 출생지 시각 보정, 대운은 변환된 양력 출생일에 대해 계산한다. Gemini 재계산에도 사용자가 확정한 평달/윤달 값을 전달한다.
- 출생 정보만으로 실제 생일이 평달인지 윤달인지 판단할 근거가 없으므로 AI가 추측해 단일 결과로 확정하지 않는다.
- 저장된 결과에는 입력 달력과 확정된 윤달 여부를 함께 남긴다.

## 제외 범위

- 1990년 이전 또는 2100년 이후 음력 출생.
- 양력 환산 결과가 1990년 이전인 날짜.
- AI가 지난 사건을 추측해 평달/윤달을 대신 확정하는 기능.
- 양력 날짜를 다시 음력 날짜로 환산하는 변환기.

## 완료 기준

- 양력 기존 기준 테스트는 그대로 통과한다.
- 알려진 평달과 윤달 입력이 서로 다른 양력 날짜로 변환되고, 변환된 날짜로 같은 원국·대운 결과를 만든다.
- ‘모름’에서 윤달이 없는 달은 평달 하나로 계산하고, 윤달이 있는 달은 두 후보를 보여준다.
- 존재하지 않는 날짜와 입력 범위 밖의 날짜를 명확히 거부한다.
