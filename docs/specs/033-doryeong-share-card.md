# 도령 한줄평 공유 카드

## 요청
- 결과 화면의 도령 한줄평을 이미지 카드로 저장하고, 방문자가 직접 공유할 수 있게 한다.
- 공유 결과에는 생년월일·출생 시각·출생지·원국 전체·계정 정보를 넣지 않는다.

## 구현 기준
- 기존 원국에서 계산한 한줄평을 카드의 유일한 개인화 문구로 사용한다. 별도 서버 저장이나 AI 호출은 하지 않는다.
- 밤하늘 분위기의 카드 미리보기와 PNG 이미지 저장 버튼을 제공한다.
- 공유 버튼은 기기의 공유 기능을 사용하고, 지원하지 않으면 한줄평과 서비스 주소를 복사한다. 방문자가 버튼을 누를 때만 공유 작업을 시작한다.
- 로컬 시험 중에는 공유 문구를 복사하고 운영 주소를 넣는다. 운영 환경에서는 현재 사이트 주소와 기기의 공유 기능을 사용한다.
- 취소·실패·복사 성공을 화면에 알리고, 모바일에서도 버튼과 문구를 읽기 쉽게 표시한다.
- 기존 사주 계산·브라우저 및 계정 저장 형식은 변경하지 않는다.

## 검증
- 공유 텍스트에 허용한 문구와 사이트 주소만 포함되는지 확인한다.
- 저장 이미지 생성과 버튼 동작을 로컬 화면에서 확인하고, 공유 실패 안내 경로를 코드와 테스트로 확인한다.
- 전체 테스트·타입 검사·빌드를 통과한다.

## 상태
- 구현 완료. 전체 203개 테스트·타입 검사·빌드 통과. 로컬 브라우저에서 카드 표시, 이미지 다운로드 시작 안내, 공유 문구 복사 안내 확인. 실제 다운로드 파일과 운영 환경의 기기 공유창, 참가자 직접 확인은 아직 하지 않음.
