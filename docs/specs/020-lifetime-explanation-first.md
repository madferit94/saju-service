# 020 평생운의 용어·근거를 먼저 읽기

## 요청

- 평생운의 긴 풀이가 십성 이름만 나열해 처음 보는 사람이 이해하기 어렵다.
- 독자가 용어의 쉬운 뜻과 개인 사주의 계산 근거를 먼저 확인한 뒤 해석을 읽도록 한다.

## 범위

1. 평생운에 나오는 십성의 뜻을 생활말로 먼저 설명한다. 대운·일간·지장간의 뜻도 함께 안내한다.
2. 각 대운의 실제 기간과 간지, 일간과 대운 천간의 관계, 지지의 중심 지장간을 해석보다 먼저 표시한다. 대운 시작 전에는 없는 간지와 십성을 만들지 않는다.
3. 기존에 저장한 Gemini 평생 풀이도 용어와 계산 근거 뒤에 배치해 저장 내용을 잃지 않는다.
4. 새 Gemini 풀이에는 계산 근거 → 쉬운 뜻 → 조건부 해석의 순서와 각 시기 구분을 요구한다. 기존 저장 자료를 재생성하도록 강요하지 않는다.

## 검증

- 화면에서 용어 설명과 계산 근거가 평생 풀이보다 앞에 오는지 확인한다.
- 서로 다른 원국의 십성·일간이 화면 근거에 맞게 반영되는지 확인한다.
- 대운 시작 전 구간과 기존 저장 풀이도 표시되는지 확인한다.
- 전체 테스트, 타입 검사, 빌드와 로컬 페이지 응답을 확인한다.

## 상태

- 2026-09-24 구현 및 자동 검증 완료. 이번 평생운에 실제 등장하는 십성의 쉬운 뜻과 대운·일간·지장간·합충 설명을 긴 풀이 앞에 배치했다.
- 각 시기에서 일간과 대운의 천간·중심 지장간 관계, 원국과의 합충 근거를 먼저 보여 준다. 대운 시작 전에는 적용되지 않은 간지를 만들지 않는다. 기존 저장 Gemini 풀이의 본문은 보존해 마지막에 표시하며, 새 생성 지시에는 근거·뜻·해석 순서를 반영했다.
- 새 테스트 3개를 포함한 전체 164개, 타입 검사, 빌드 통과. 로컬 페이지 HTTP 200. 참가자 실제 화면 확인 전. 기존 저장 문장 자체는 자동으로 새 문체로 바뀌지 않는다.
