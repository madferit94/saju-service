# 사주 해석의 읽기 순서와 문장 품질

## 목적

같은 시기 해석이 여러 영역에 중복되어 핵심이 묻히는 문제를 줄이고, 원국·대운·세운·생활 주제의 연결을 쉽게 읽게 한다.

## 범위

- 결과 초반에 현재 대운의 주제, 선택 연도의 세운, 관심 생활 주제로 이어지는 짧은 길잡이를 둔다. 각 문장은 계산된 근거를 가리킨다.
- 인생 4계절에는 현재 이유와 개운법을 먼저 표시하고, 과거·미래 대운 상세는 기본적으로 접어 둔다. 평생운·대운 시간표에 같은 내용이 반복되는 경우 하나의 핵심 설명과 근거 이동 링크로 정리한다.
- 생활 주제별 운은 원국 자리·대운·선택 연도의 세운이 실제로 어떻게 연결되는지 보여준다. 단지 연도와 십성 이름만 치환한 문장, 실제 합충이 없는데 있다고 암시하는 문장은 고친다.
- 가변 명리 용어의 조사 오류를 고치고, 나이별 생활 맥락에 맞는 조언을 사용한다. 60세 이후에 직장·고객·납기를 기본 전제로 하지 않는다.
- 과거 사건·미래 결과를 확정하지 않는다. 건강·재물·관계는 현실 조건과 함께 읽는다.

## 검증

- 가상 원국과 연도 조합에서 서로 다른 해석과 실제 계산 근거 연결을 확인한다.
- 과거·현재·미래 대운의 중복 노출, 조사 오류, 후반기 조언을 확인한다.
- 기존 계산·저장·Gemini 동의 경로의 회귀 테스트와 타입 검사·빌드·실제 화면을 확인한다.

## 상태

구현·검증 완료. 현재 흐름 길잡이, 상세 기본 접기, 원국·대운·세운 연결, 조사와 후반기 문장을 반영했다.

## 검증 결과

- 독립 테스트에서 생활 운의 실제 세운·대운 근거, 조사, 20세·60세 경계의 현재 조언, 상세 기본 접기를 확인했다.
- 저장·Gemini 동의·기존 사주 계산 등 기존 동작을 포함한 전체 183개 테스트와 타입 검사, Next.js 프로덕션 빌드가 통과했다.
- 로컬 화면에서 연속 읽기 순서와 생활 운 카드, 계절 상세의 기본 접힘을 확인했다.
