# 022 오늘의 운세 접기·펼치기

## 목표

긴 사주 결과 화면에서 오늘의 운세를 이용자가 원할 때 열어 읽는다.

## 동작

1. 사주 결과가 표시되면 오늘의 운세 영역은 처음에 접혀 있다.
2. '오늘의 운세' 제목을 클릭하거나 키보드로 활성화하면 날짜, 살릴 점, 주의할 점, 오늘 해볼 일, 계산 근거가 함께 펼쳐진다. 다시 활성화하면 접힌다.
3. 접힘 상태는 접근성 속성으로 전달한다. 운세 자료 갱신과 오류 재시도 기능은 유지한다.

## 검증

- 처음에는 세부 내용이 숨겨지고, 제목을 누르면 표시되며 다시 누르면 숨겨지는지 확인한다.
- 키보드 조작, 타입 검사, 관련 테스트와 배포용 빌드를 확인한다.

## 확인 상태

- 접기·펼치기 상태와 접근성 속성을 확인하는 관련 테스트 1개 통과.
- 전체 테스트 171개와 타입 검사, 배포용 빌드 통과.
- 로컬 브라우저에서 초기 접힘, 클릭 후 펼침, 재클릭 후 접힘을 확인. 참가자 화면 확인 전.
