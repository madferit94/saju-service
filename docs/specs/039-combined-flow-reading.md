# 원국과 시기 관계를 함께 읽는 해석

## 요구와 범위
- 원국의 월령·뿌리·투간·생조 비중·조후와 시기 천간·모든 지장간의 조합을 공통 해석 자료로 만든다.
- 같은 십성이라도 원국의 도움/소모 조건에 따라 기회와 부담 설명이 달라진다. 합·충은 조율할 생활 영역으로 설명하며 무조건적인 길흉으로 합산하지 않는다.
- 로컬 대운·연운·월운과 Gemini가 같은 조합 자료를 사용한다. 미성년/후반기 문장 보호를 유지한다.
- 근거 접기 UI는 추가하지 않는다. 계산된 근거 ID는 내부 자료이며 개인 사건을 생성하지 않는다.
## 검증
- 서로 다른 원국에 같은 운을 적용한 대조, 근거의 실제 글자·자리 일치, 기존 경계 계산과 연령별 해석 회귀를 독립 테스트한다.
- 타입 검사·전체 테스트·빌드·화면 확인을 수행한다.
