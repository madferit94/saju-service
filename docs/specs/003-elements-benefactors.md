# 003 오행과 귀인을 함께 보는 결과

## 목적

하나의 특징만으로 단편적으로 풀이하지 않도록, 오행의 위치와 선택한 여러 귀인을 계산 근거와 함께 표시한다.

## 계산 범위

- 오행: 네 기둥의 천간과 지지 대표 오행 8자 개수. 계절 가중치·지장간을 합산한 강약 수치는 아니다.
- 천을귀인: 일간에 따른 해당 지지를 네 기둥에서 찾는다.
- 태극귀인: 일간에 따른 해당 지지를 네 기둥에서 찾는다.
- 문창귀인: 《삼명통회》에 실린 규칙에 따른 해당 지지를 네 기둥에서 찾는다. 다른 유파의 규칙과 다를 수 있다.
- 월덕귀인: 월지에 따른 해당 천간을 네 기둥에서 찾는다.
- 귀인이 있어도 자동으로 길하다고 단정하지 않고, 없어도 도움이나 가능성이 없다는 뜻으로 해석하지 않는다.

- 태극귀인·문창귀인: https://www.shidianguji.com/book/SK1610/chapter/1ktkuwj016kui
- 월덕귀인: https://www.shidianguji.com/zh/book/SK1610/chapter/1kf5v6v49rvad

## 완료 조건

1. 오행의 개수와 어느 기둥에 해당하는지 확인할 수 있다.
2. 네 종류의 귀인에 대해 계산 기준과 일치한 기둥 또는 해당 없음이 보인다.
3. 계산 예제와 화면 표시를 확인한다.

## 검증 결과

- `npm run check`에서 천을·태극·문창·월덕귀인의 기준과 중복 일치·해당 없음을 포함한 테스트 33개가 통과했다.
- 브라우저에서 오행의 기둥별 위치와 네 귀인 카드, 일치 기둥 및 한계 안내가 표시되는 것을 확인했다. 참가자 화면 확인 전.
