# 023 쉬운 말로 읽는 운세

## 목표

오늘의 운세와 같은 공통 풀이에서 사주 용어를 모르는 이용자도 자신의 운세를 자연스러운 문장으로 읽는다.

## 동작

1. 활용점·주의점·오늘 해볼 일 본문에 `확인된 결합`, `천간합`, `지지충` 등의 계산 용어와 간지 나열을 넣지 않는다.
2. 계산된 관계가 있으면 가족·일·가까운 관계·앞으로의 계획처럼 생활 영역을 먼저 말하고 현실적인 확인 행동을 제안한다.
3. 자세한 계산 근거에는 실제 간지와 전통 용어를 남기되 바로 옆에 쉬운 뜻을 문장으로 설명한다. 원래 계산 판정은 바꾸지 않는다.
4. 기존 사주 계산 규칙을 사용하며 외부 AI 호출을 추가하지 않는다.

## 검증

- 같은 계산 결과에서 본문은 쉬운 문장이고, 근거에는 실제 합·충과 대상 간지가 남는지 확인한다.
- 다른 간지 관계에서도 문장이 깨지거나 잘못된 관계가 붙지 않는지 확인한다.
- 관련 테스트, 전체 테스트, 타입 검사, 배포용 빌드, 로컬 화면을 확인한다.

## 확인 상태

- 여러 출생 정보·날짜의 본문에 기술 용어와 원시 간지가 노출되지 않는지, 합·충 근거에는 실제 간지와 쉬운 설명이 남는지 확인하는 신규 테스트 2개 통과.
- 전체 테스트 173개와 타입 검사, 배포용 빌드 통과.
- 로컬 브라우저에서 오늘의 운세 본문이 일상 언어로 표시되는 것을 확인. 참가자 화면 확인 전.
