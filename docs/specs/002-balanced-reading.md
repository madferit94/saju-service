# 002 균형 잡힌 로컬 사주 해석

## 목적

이용자가 대운, 오행, 귀인 근거를 함께 보고 삶의 흐름을 돌아본다. 오랜 경력의 역술가처럼 차분하고 솔직한 문체를 지향하지만, 실제 전문가가 상담하거나 AI가 문장을 작성했다고 주장하지 않는다.

## 범위

- 계산 결과를 이용자 브라우저에서 규칙으로 조합해 결과 화면에 표시한다. 로컬 결과 작성 자체는 Gemini 등 외부 AI로 전송하지 않는다. Gemini 기능은 별도 동의를 받아 별도 영역에서 제공한다.
- 삶 전반, 과거, 현재, 미래, 진로, 관계, 돈, 주의할 점을 보여준다.
- 강점과 부담을 함께 쓰고, 과거 사건이나 미래 결과를 단정하지 않는다.
- 오행 대표 글자 8개의 개수는 참고치이며 계절·지장간 등을 반영한 강약 판정이 아님을 밝힌다.
- 입력 변경 시 이전 결과를 지우고 다시 계산한다.

## 완료 조건

1. 추가 동의나 API 키 없이 결과 화면에서 해석을 볼 수 있다.
2. 과거·현재·미래 대운과 오행·귀인 근거를 함께 표시한다.
3. 로컬 결과 생성 경로에는 외부 AI 호출이 없다.
4. 자동 검사와 브라우저 표시를 확인한다.

## 검증 결과

- `npm run check`의 타입 검사와 테스트 33개가 통과했다. 로컬 해석의 근거·균형·입력 변경을 테스트했다.
- 서울·뉴욕 예시를 브라우저에서 입력해 별도 요청 없이 결과 화면에 해석이 표시되는 것을 확인했다.
- `app/`, `lib/`, `.env.example`에서 Gemini 호출 경로와 인증값 참조가 제거된 것을 확인했다. 참가자 화면 확인 전.
- 이후 Gemini 해석 추가로 해당 당시의 UI가 대체되었고, 로컬 규칙은 `007-local-reading-option.md`에서 다시 결과 화면에 연결했다.
