# 019 질문 칸 없는 사주 결과 읽기

## 요청

- 결과 화면의 ‘내 경험에 비춰보기’와 ‘경험을 돌아볼 질문’은 대화형 서비스처럼 보인다. 이용자가 묻는 대신 계산된 사주를 바탕으로 완성된 해석을 읽고 싶다.

## 범위

1. 성인 11개·미성년 5개 생활 운 카드에서 질문 칸을 없애고, 각 카드에 해당 원국 자리의 십성과 선택 연도 세운의 관계를 생활말로 설명한다. 연애·자녀·건강 등은 실제 사건이나 의학적 상태를 단정하지 않는다.
2. 대운 카드와 이전에 저장한 긴 상담 화면에서 보이는 회고 질문을 없앤다. 이미 있는 활용점·부담·행동·계산 근거는 계속 보여 준다.
3. 예전 저장 해석의 `reflection`·`question` 필드는 호환성을 위해 유지하되 화면에서 표시하지 않는다. 새로 쓰는 기본 프롬프트도 대화형 질문 대신 조건과 판단 기준을 요청한다.
4. Gemini 전송 동의나 호출 수를 늘리지 않는다. 생활 운의 새 설명은 로컬 계산으로 만든다.

## 검증

- 다른 원국·연도에서 카드 설명이 달라지고, 각 카드의 실제 간지·십성이 설명에 연결되는지 확인한다.
- 결과 화면 HTML에 질문 제목과 물음표가 붙은 회고 칸이 없는지 확인한다. 기존 저장 상담 자료를 열 때도 질문 칸을 숨긴다.
- 전체 테스트, 타입 검사와 빌드를 실행한다. 참가자가 실제 화면을 확인하기 전에는 직접 확인했다고 기록하지 않는다.

## 상태

- 2026-09-24 구현 및 자동 검증 완료. 생활 운 16개에 원국 자리·십성과 선택 연도 간지를 연결한 설명을 추가했다. 질문 제목은 생활 운·대운 상세·이전 상담 화면에서 표시하지 않는다.
- 기존 `reflection`·`question` 저장 필드는 읽기 호환을 위해 보존한다. 새로운 Gemini 프롬프트에는 질문 대신 평서문의 판단 기준을 요청한다.
- 관련 화면·계산 테스트 22개와 전체 161개 테스트, 타입 검사·빌드 통과. 로컬 개발 페이지 HTTP 200. 참가자 화면 확인 전. 실제 개인 사주나 Gemini 실응답의 문체는 이번 변경에서 검증하지 않았다.
