# 하나의 내 사주 보기 버튼

## 요청
- 출생 정보 입력의 Gemini/AI 없이 보기 두 버튼을 없애고 “내 사주 보기” 한 버튼으로 통합한다.
- 기본 계산 풀이를 먼저 보여 주고 Gemini 풀이가 준비되면 같은 결과에 덧붙인다.

## 구현 기준
- 제출 버튼은 하나이며 이 버튼으로 계산과 Gemini 요청이 시작된다. 계산된 사주 자료의 Google 전송은 버튼 바로 앞에서 짧게 알린다.
- Gemini가 실패하거나 서버 키가 없더라도 이미 계산된 사주 결과는 그대로 볼 수 있고 실패와 재시도 수단을 보여 준다.
- 윤달 후보 선택 때는 후보를 고른 뒤 선택한 사주 하나만 요청한다. 저장본을 열거나 화면을 이동할 때 새 AI 요청을 시작하지 않는다.
- 사주 계산 규칙과 저장 결과 형식은 변경하지 않는다.

## 검증
- 독립 서브에이전트가 단일 버튼, Gemini 요청 횟수, 윤달 후보, 저장본 열기, 실패 후 기본 결과 유지 동작의 테스트를 작성·실행한다.
- 타입 검사, 전체 테스트, 빌드와 로컬 입력 화면을 확인한다.

## 상태
- 구현 완료. 입력 화면의 두 버튼을 “내 사주 보기” 하나로 바꾸고, 제출 시 기본 계산 뒤 Gemini 풀이를 자동 요청함.
- 독립 관련 테스트 10개, 전체 221개 테스트, 타입 검사, 배포용 빌드 통과. Gemini 실패 후 기본 결과 유지와 재시도, 윤달 후보 한 번 요청, 저장본 복원 시 요청 없음 확인.
- 브라우저 보안 정책으로 로컬 화면의 직접 확인은 차단됨. 참가자 화면 확인 전. GitHub·Vercel 미반영.
