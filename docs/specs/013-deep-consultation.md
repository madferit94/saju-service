# 심층 명리 분석과 8장 상담형 풀이

## 목표
30년 경력 상담가에게 긴 상담을 받는 듯한 분석 밀도: 근거·상반 조건·실생활 예시·확인 질문·실천 방향을 제공한다. 실제 경력 또는 상담 시간을 사칭하지 않는다.

## 명리 판정 v1
- 신강/신약: 일간을 제외한 천간 및 지장간을 계절과 위치 가중치로 비교하는 **서비스 자체 휴리스틱(비교용 규칙)**. 과학적 확률이나 전통의 공인 점수가 아니다.
- 천간 각10, 년지10·월지30·일지15·시지10; 지장간 1개100%, 2개70/30%, 3개60/30/10%. 계절 원소에 대한 왕상휴수사 상대 가중치1.5/1.2/1/0.8/0.6을 적용. 월지 토는 계절 말 토의 단순 모델임을 명시.
- 생조 비율(일간과 같은 오행 및 일간을 생하는 오행) 40% 미만 신약 경향, 60% 초과 신강 경향, 그 사이 중화 범위. 월지 가중치 ±20%와 계절 배율 제거 시 결과가 바뀌면 경계 판정. 15% 미만/85% 초과는 특수격 검토 대상으로 일반 억부 용신 자동 확정 금지.
- 격국: 월지 지장간의 본기와 투간(일간 제외 천간에 나타남)을 확인해 후보만 제시. 건록·양간 양인 조건 별도 표시. 성격·파격·합화·종격을 자동 확정하지 않는다.
- 용신: 강약에 따른 억부 후보와 계절의 한난 보완(조후)을 분리한다. 월령 중심 격국용신과 같은 뜻으로 혼용하지 않는다. 중화/경계/특수격은 보류 사유를 제공한다. 오행 부족만으로 선정하지 않는다.
- 각 판정의 계산 내역·반대 근거·적용 범위를 로컬 화면과 AI 자료에 함께 제공한다.

## 상담형 풀이
- 8장: 원국, 강약, 격국/용신, 평생/전환기, 일/배움, 돈/자원, 가까운 관계, 선택/실천.
- 한 장 3~4절. 각 절은 제목·설명(최소160자)·2개 이상 계산근거 ID·반대 조건·가정 예시·확인 질문·실천 항목. 모델에는 절당 본문300~500자를 요청한다.
- 정확한 근거 ID만 허용한다. 예시는 실제 사건을 맞혔다는 주장 없이 제시한다. 미성년 연령, 한글 독음, 과거/미래, 조건부 판단 구분.
- Gemini gemini-3.5-flash-lite 유지. 서버가 재계산한 자료만 전송한다. 기존 개인정보 동의 후 사용자가 8장 생성을 시작한다.
- 장별 순차 생성, 진행 표시, 장별 형식 검증 및 1회 수정 재시도. 오류 시 완성 장은 남겨두고 누락 장부터 이어서 작성한다. 연도·분석 버전이 바뀌면 이전 풀이임을 표시한다.
- 전송 항목에 새 심층 분석 근거를 명시. 원래 생일·도시·개인질문은 모델에 전송하지 않는다.

## 저장·호환
SavedSajuResult에 선택적 consultation 필드(version1, analysisVersion1, year, chapters)를 추가한다. 과거 자료는 계속 복원한다. 완료된 장마다 기존 로컬 저장 정책을 적용하고 계정에서 연 결과는 기기에 자동 저장하지 않는다. 계정에 저장 버튼은 상담 자료도 포함한다.
실패·계정 전환·다른 결과로 이동 후 늦은 응답이 이전 결과를 덮지 않도록 기존 요청 번호 검사를 적용한다.

## 검증
계절/지장간/투간/경계/특수격 보류, 서로 다른 사주 차이, 근거 참조 유효성, 짧거나 누락된 장 거부, 부분 저장·복원, 이전 데이터 호환, 계정 전환 회귀. 비구현 에이전트 테스트와 가상 자료 실 API 검증. 전 사례 명리 전문가 감수는 별도 미완료 상태로 명시.

## 상태
구현·검증 완료. 참가자 결과 확인 전.
- `lib/saju/deep-analysis.ts`의 명시적 비교 규칙, 로컬 근거 화면, 기존 종합 해석에 analysisVersion1 연결.
- `/api/consultation` 장별 생성과 1회 형식 수정 재시도, 진행·멈추기·재개, 부분 결과 저장, 계정 저장 자료 호환 구현.
- 비구현 서브에이전트가 신규 25개 검사를 추가. 타입 검사·전체 118개·프로덕션 빌드 통과.
- 실제 가상 출생 자료로 Gemini 8장·24절·설명/반대조건/예시/질문/행동 합계 16,586자 생성 및 구조 검증. 사용자 출생 정보는 이 테스트에 사용하지 않음.
- 생성 초안에서 강약을 체력·번아웃으로 연결하는 부적절한 설명을 발견해 금지 표현 검증과 프롬프트를 보완하고 해당 장 재생성 확인.
- 기존 종합 해석 API도 HTTP200 및 analysisVersion1을 확인. 이전의 미포함 안내가 새로운 계산 범위 설명으로 바뀌었음.
- 실행 중인 화면에서 심층 분석 카드, 판정 보류 사유, 동의 전 상담 버튼 비활성화와 이전 해석 안내를 확인.
- 근거 ID 검증은 문장의 모든 명리학적 주장을 증명하지 않는다. 가중치와 전 사례 해석에 대한 전문 감수는 미완료이며, 임의의 수치로 운명·건강·성과를 확정하지 않는다.
