# 006 Gemini 기반 개인 사주 해석

## 목적

계산이 끝난 사주, 오행, 귀인과 대운을 바탕으로 개인화된 해석을 제공한다. 말투는 오랜 경험을 쌓은 역술가처럼 차분하고 솔직하게 구성하되, 실제 경력이 있는 사람이 상담하거나 미래가 확정된 것처럼 주장하지 않는다.

당시 결정에 따라 기존 `002-balanced-reading.md`의 로컬 전용 해석을 Gemini 해석으로 확장했다. 이후 로컬 해석도 함께 제공하기로 한 변경은 `007-local-reading-option.md`에 기록한다. 사주 계산은 계속 기존 `lib/saju`가 담당한다.

## 사용자 흐름

1. 이용자가 출생 정보를 제출하면 기존 기능이 사주·오행·귀인·대운을 계산한다.
2. Gemini 전송 전에 어떤 계산 정보가 전송되는지 알리고 이용자의 명시적 동의를 받는다.
3. 동의한 경우 서버가 Gemini에 해석을 요청하고 결과 창에 내용을 표시한다.
4. 계산 결과와 성공한 해석을 이용자의 현재 브라우저 `localStorage`에 저장한다. 같은 브라우저에서 다시 열면 마지막 저장 결과를 복원한다.
5. Gemini 호출이 실패하면 실패 사실과 재시도 버튼을 보여준다. 로컬 해석은 별도 표시로 언제나 제공하고, 이를 Gemini 결과인 것처럼 섞거나 표시하지 않는다.

## 해석 입력과 개인정보

- 서버에서 이미 계산된 네 기둥, 일간, 대표 오행 분포와 계산 방식, 선택된 귀인의 종류·근거, 각 대운의 간지·시작/끝 연도·현재/과거/미래 구분을 해석 입력으로 사용한다.
- 이름, 생년월일, 출생 시각, 출생 국가·도시, 시간대, 경도 등 원래 입력 정보는 Gemini 요청에 포함하지 않는다.
- 계산 정보도 개인 사주를 드러낼 수 있으므로, 전송 전에 Gemini로 전달될 수 있음을 분명히 알리고 동의를 필수로 받는다. 동의하지 않으면 요청하지 않는다.
- API 키는 `GEMINI_API_KEY` 환경 변수로 서버에서만 읽는다. 브라우저 응답, `NEXT_PUBLIC_*` 변수, `localStorage`, URL, 로그에 키를 기록하지 않는다.
- `localStorage`에는 입력 정보, 계산 결과, 해석 결과와 저장 시각을 버전이 있는 단일 최신 결과로 보관한다. API 키와 동의 토큰은 저장하지 않는다.
- 저장된 결과는 현재 브라우저/기기 안에서만 복원된다. 다른 기기에서 열 수 있는 링크나 서버 저장은 이번 범위에서 다루지 않는다. 브라우저 저장 공간을 지우면 함께 삭제된다.
- 출생 정보 또는 계산 조건을 바꾸어 새 계산을 시작하면 화면의 기존 결과를 지우고, 새 계산 결과가 만들어질 때 저장 데이터를 갱신한다. 저장 데이터가 없거나 손상된 경우 앱이 중단되지 않도록 복원 실패를 처리한다.

## Gemini 모델과 응답

- 모델 ID: `gemini-3.5-flash-lite`.
- Gemini 호출은 Next.js 서버 API 경로에서만 수행한다.
- 모델에는 사주를 계산하지 말고 전달된 계산값과 근거만 해석하도록 지시한다. 제공되지 않은 기둥·오행·귀인·대운을 만들어내지 않는다.
- 2026-09-23 요청에 따라 프롬프트에서 네 기둥 각각의 한자와 한글 독음·오행 풀이, 서로의 관계 분석, 필드별 구체적 근거와 현실 조언을 명시한다. 기존의 짧은 일반 지시에서 근거 → 상호작용 → 가능성과 부담 → 현실에서 점검할 점을 종합하도록 보강했다.
- 구조화된 응답을 사용하고 서버에서 필수 필드, 문자열 길이, 대운 인덱스 및 참조 대상을 검증한 뒤 화면에 전달한다.
- 응답에는 다음을 포함한다.
  - 삶 전반: 사주 구성과 오행 분포를 함께 읽은 요약과 해석의 한계.
  - 귀인: 확인된 종류와 해당 기둥을 근거로 한 설명. 귀인의 유무를 인생 결과로 단정하지 않는다.
  - 대운별 해석: 화면에 표시되는 각 대운마다 기간과 간지, 주요 흐름, 활용할 점, 부담·주의점, 현실적인 조언을 제공한다.
  - 과거 대운에는 실제 사건을 맞혔다고 주장하지 않고, 이용자가 경험과 비교할 질문을 제공한다.
  - 진로·일, 관계, 돈은 삶 전반 해석의 하위 주제로 제공한다.
  - 미래 대운은 가능성과 준비 방향으로 표현하고 확정적인 사건·성과를 예언하지 않는다.
- 결과 문체는 일방적인 칭찬만 하지 않고 강점과 어려움, 선택에 따른 부담을 함께 다룬다. 공포를 조성하거나 의료·법률·투자 결정을 단정하지 않는다.
- 응답 본문은 텍스트로 표시하며 모델이 반환한 임의의 HTML을 실행하지 않는다.

## 오류와 재시도

- API 키가 없거나 호출에 실패하면 해석 생성 실패와 사용자가 할 수 있는 재시도 방법을 표시한다. 비밀값과 내부 오류 상세는 노출하지 않는다.
- 네트워크 오류, 크레딧 부족(HTTP 402), 요청 제한(HTTP 429), 시간 초과, 모델 응답 형식 오류를 구분 가능한 사용자 안내로 처리한다.
- 재시도는 이용자가 직접 실행한다. 재시도 중에는 중복 제출을 막고 진행 중 상태를 보여준다.
- 실패 응답을 `localStorage`의 성공 해석으로 저장하지 않는다. 계산 결과는 남겨 재시도할 수 있다.
- 새 입력의 결과 생성에 실패해도 이전 사람의 해석이 새 입력 결과처럼 보이지 않게 입력과 결과의 연결을 확인한다.

## 이번 범위에서 제외

- 계정, 서버 데이터베이스, 다른 기기 간 동기화, 공유 링크와 서버 저장.
- Gemini와 자유 대화, 외부 검색·도구 사용, 모델에게 사주 자체를 계산하게 하는 기능.
- 이용자가 과거 사건이나 개인 사정을 자유 입력해 추가 분석받는 기능.
- 기존 귀인 종류나 사주 계산 규칙의 변경.

## 완료 조건

1. 명시적 동의 전에는 Gemini 요청이 발생하지 않고, 거부하면 계산 결과를 확인할 수 있다.
2. 요청은 서버에서 지정 모델 `gemini-3.5-flash-lite`를 사용하며 브라우저에서 API 키를 찾을 수 없다.
3. 유효한 모델 응답이 검증된 뒤 삶 전반, 오행·귀인, 각 대운, 진로·관계·돈 해석이 결과 창에 나타난다.
4. 과거 경험 비교 질문과 미래의 불확실성 안내가 포함되며, 근거 없는 확언·과장된 전문가 경력 주장이 없다.
5. 계산 결과와 성공한 해석은 같은 브라우저에서 새로고침 후 복원되고, 입력을 바꾸면 이전 해석이 섞이지 않는다.
6. 키 누락, 네트워크 실패, 제한 초과와 잘못된 응답에서 가짜 해석을 보이지 않고 재시도할 수 있다.
7. 자동 검사와 화면에서 동의·성공·실패·재시도·복원을 확인한다.

구현 완료. 자동 검사와 화면의 동의·저장 복원·크레딧 부족·재시도 동작을 확인했다. 실제 Gemini 성공 응답은 Google 프로젝트의 선불 크레딧 부족으로 아직 확인하지 못해 전체 완료 표시는 보류한다.

## 구현 및 검증 기록

- Next.js 서버 API 경로가 `gemini-3.5-flash-lite`와 구조화된 응답을 사용한다. Gemini에는 계산 결과만 전달하고 생년월일·출생 시각·출생 도시는 포함하지 않는다.
- `npm run check`: 타입 검사 및 테스트 46개 통과.
- `npm run build`: 통과. 이 환경의 Node 프로세스는 기본 실행 메모리가 부족해 `NODE_OPTIONS=--max-old-space-size=4096`로 실행했다.
- 브라우저에서 동의 전 요청 차단, 계산 자료의 `localStorage` 복원, 동의 후 크레딧 부족 안내와 재시도 표시, 실패 응답을 성공 결과처럼 저장하지 않는 동작을 확인했다. 테스트 입력은 확인 뒤 브라우저 저장 공간에서 지웠다.
- 실제 Gemini 요청은 Google API가 HTTP 402 `RESOURCE_EXHAUSTED`(선불 크레딧 소진)를 반환했다. 앱에서 이를 크레딧 안내와 재시도 가능한 오류로 표시한다. 크레딧 충전 후 성공 응답 및 대운별 해석 화면을 다시 확인해야 한다.
