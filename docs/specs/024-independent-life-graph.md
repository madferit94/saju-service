# 사주 기반 인생 그래프와 현재 4계절 분리

## 이용자 요청

- 인생 그래프는 계절을 이어 그린 그래프가 아니라, 개인 원국과 실제 대운에 따른 삶의 흐름을 보여준다.
- 4계절은 그래프와 별도 영역으로 두고, 현재 어떤 계절인지, 왜 그렇게 읽는지, 그 시기에 실천할 개운법을 설명한다.
- 그래프와 계절의 계산 근거를 구분해 표시하며, 과거는 경험과 비교하고 미래는 선택의 참고로 읽는다.

## 확정할 계산 기준

- 그래프는 대운마다 원국의 네 기둥과 맺는 **활용할 관계 단서**(천간합·지지육합)와 **조정할 관계 단서**(지지충)의 개수를 두 선으로 보여준다. 세로축은 관계 단서의 개수다. 같은 지지 반복은 별도 근거로 표시하고 어느 한쪽 점수로 넣지 않는다. 숫자가 큰 시기가 더 좋은 운이라는 뜻은 아니다. 계절 범주를 높낮이 값으로 재사용하지 않는다.
- 두 선은 한 대운 안에서 값이 일정한 계단형으로 그리고, 각 대운의 시작·끝 연도와 현재 위치를 표시한다. 계산된 개수와 근거는 텍스트 목록에서도 확인할 수 있다. 기존 합·충 계산 범위를 넘어서는 형·해·파나 용신의 길흉 판정은 넣지 않는다.
- 원국·출생지 보정·대운 시기는 기존 계산을 유지한다. 계산값을 확률, 수명, 확정된 사건처럼 표시하지 않는다.
- 현재 계절의 분류는 기존 대운 천간·지지 본기 십성 규칙을 유지하고, 대표 계절·보조 계절·해당 대운·원국과의 관계를 설명한다.
- 개운법은 해당 대운의 십성·원국과의 관계에서 나온 기회와 부담을 생활에서 확인하고 조정하는 구체적 실천이다. 색·방위·물건이나 건강·금전 결과를 보장하는 표현을 붙이지 않는다.

## 화면과 검증

- 그래프와 4계절은 독립된 제목·설명·바로가기를 갖는다.
- 그래프에는 실제 대운 구간과 현재 위치, 세로축 의미, 구간별 근거와 텍스트 대체 설명을 제공한다.
- 4계절은 현재 계절을 먼저 보여주고 이유·활용점·부담·개운법을 읽게 한다. 다른 대운은 펼쳐서 읽는다.
- 가상 입력 여러 건에서 원국 및 대운별 차이, 경계 연도, 대운 시작 전, 모바일·키보드 읽기, 이전 저장본 호환을 확인한다.

## 상태

개운법은 이용자 답변으로 생활 실천을 확정했다. 그래프 세로축은 이용자 답변이 없어 원국·대운 관계 단서 개수로 적용했다. 합·충은 좋고 나쁨의 점수가 아님을 화면에 표시한다. 이용자가 다른 기준을 선택하면 조정한다.

## 검증 결과

- 독립 테스트에서 가상 원국 3건의 대운별 합·충·반복을 별도 계산과 비교했고 현재·경계·대운 시작 전을 확인했다.
- 로컬 화면에서 그래프와 4계절의 독립 영역, 현재 표시, 좁은 화면의 가로 스크롤과 텍스트 대체 목록을 확인했다.
- 전체 183개 테스트, 타입 검사, Next.js 프로덕션 빌드가 통과했다.
