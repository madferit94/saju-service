# 단순한 사주 인생 흐름과 전성기 후보

## 이용자 요청

- 기존 합·충 두 선과 많은 수치가 복잡하다. 하나의 그래프에서 삶의 흐름과 전성기처럼 두드러지는 시기를 한눈에 보고 싶다. 전성기의 기준은 이용자 답변에 따라 **삶 전반의 확장기**로 둔다.
- 인생 4계절은 독립된 영역으로 유지한다.

## 해석 기준

- 각 대운의 실제 연도·간지와 원국을 사용하고, 서비스의 기존 강약·도움 오행 분석이 **조건부 후보**를 제시한 경우에만 그 후보와 대운의 천간·지지 본기 오행이 만나는 정도를 시기 비교에 활용한다.
- 원국 강약이나 도움 오행이 보류된 경우에는 전성기를 임의로 확정하지 않는다. 이때는 원국과 대운의 합·충·반복이 두드러지는 구간을 `변화가 많은 시기`로 보여주며, 좋고 나쁨의 결론으로 바꾸지 않는다.
- 조건부 후보가 있는 경우에도 가장 높은 구간은 `전성기 후보`이며 실제 성취·건강·관계·수명이나 해당 시기의 무조건적인 길운을 예측하지 않는다. 동점은 같은 수준으로 표시한다.
- 그래프는 하나의 상대적 흐름 선과 현재 위치, 강조 구간 1~2개만 보여준다. 숫자 축과 긴 기간 목록은 기본 화면에서 치우고, 계산 근거는 펼쳐 읽는다.

## 검증

- 가상 원국 여러 건에서 조건부 후보와 보류 원국을 각각 확인한다.
- 대운 경계와 시작 전, 동점, 저장본 호환, 모바일·키보드·스크린리더 설명을 확인한다.
- 전체 Test, 타입 검사, 빌드와 로컬 화면을 확인한다.

## 상태

구현·자동 검증 완료. 이용자가 삶 전반의 확장기를 선택했다.
