# 008 사주 해석의 깊이와 한자 풀이

## 문제

현재 로컬 해석은 사주 근거와 무관하게 반복되는 일반 문장이 많고, 네 기둥의 한자 간지에 한글 독음과 오행 관계 풀이가 충분히 붙지 않는다. Gemini 프롬프트도 항목을 채우라는 짧은 지시 위주여서 종합 해석의 깊이를 유도하지 못한다.

## 목표

네 기둥, 일간과 월지, 오행 상호작용, 귀인의 계산 근거, 개별 대운 흐름을 이어서 설명한다. 30년 경력자라고 주장하지 않으면서도 전통을 오래 공부한 상담가처럼 단정하고 솔직한 목소리로 말한다.

## 요구사항

1. 네 기둥마다 한자, 한글 독음, 천간·지지의 오행을 함께 표시한다.
2. 각 기둥의 전통적 관점과 일간에 대한 천간·지지의 관계를 구분해 설명한다.
3. 오행은 개수 나열에 그치지 않고 실제 상생·상극 관계와 그에 따른 강점·긴장을 연결한다. 미계산한 강약·용신을 단정하지 않는다.
4. 네 가지 귀인을 각각 계산 근거, 해당 기둥, 참고할 수 있는 의미로 설명한다. 발견되지 않아도 부정적 운명으로 해석하지 않는다.
5. 각 대운은 해당 간지·오행 근거에 맞게 개별 작성하고, 활용점·부담·구체적인 현실 조언·회고 질문을 포함한다.
6. 과거에는 경험 비교를 돕고 미래에는 가능성과 준비를 말한다. 미래를 확정하거나 무조건 듣기 좋은 문장으로 포장하지 않는다.
7. 로컬 템플릿과 Gemini 프롬프트 모두 위 요구를 반영한다. 로컬 해석은 네트워크를 사용하지 않고, Gemini는 기존 별도 동의 후에만 사용한다.

## 완료 조건

- 로컬 화면에 네 기둥별 한자·독음·오행 및 관계 해석이 나타난다.
- 각 대운의 기간·간지와 로컬 문구가 서로 맞고, 실제 계산 근거를 설명한다.
- Gemini 프롬프트가 각 기둥과 대운의 개별 분석, 한글 풀이, 근거에서 현실 조언으로 이어지는 구조를 요구한다.
- 테스트·타입 검사·빌드가 통과하고 로컬 결과 화면을 확인한다.
- 실제 Gemini 성공 경로가 검증되지 않았으면 이를 분명히 남긴다.

## 상태

완료. 다만 Gemini 성공 응답의 문체와 깊이는 계정 크레딧 부족으로 실응답에서 아직 검증하지 못했다.

## 구현 및 검증 결과

- 로컬 해석에 네 기둥별 한자·한글 독음·천간/지지 오행, 기둥의 전통적 관점, 일간과의 오행 관계를 추가했다. 대운별로도 기존에 해당하는 간지·오행 관계와 과거/현재/미래별 조언·주의점·회고 질문을 유지한다.
- Gemini 지시문을 종합형으로 보강했다. 네 기둥을 모두 순서대로 풀이하고 한자에 한글 독음·오행 관계를 붙이며, 귀인의 계산 근거, 대운별 상호작용, 근거에서 현실 조언으로 이어지는 문장을 요구한다.
- `npm run check`: 타입 검사 및 테스트 50개 통과. 테스트는 네 기둥 풀이의 한자·독음·오행·일간 관계 연결과 대운별 기간/간지/상태 문구를 확인한다.
- `npm run build`: 통과 (`NODE_OPTIONS=--max-old-space-size=4096`).
- 브라우저에서 저장된 결과 복원 후 네 기둥 풀이와 대운별 로컬 해석이 화면에 표시되는 것을 확인했다. 참가자 확인 전.
- 제한: 직전 실제 Gemini 호출에서 Google API 크레딧 부족(HTTP 402)이 확인되어, 보강된 프롬프트로 만든 AI 답변은 아직 검토할 수 없다. 실제 Gemini 결과의 깊이와 정확성은 크레딧 사용 가능 후 확인해야 한다.
