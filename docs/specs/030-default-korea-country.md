# 출생 국가 기본값을 대한민국으로 표시

## 요청
- 출생 국가의 처음 보이는 값은 대한민국이다.
- 이용자가 원하면 목록에서 다른 나라를 선택할 수 있다.

## 구현 기준
- 국가 목록을 불러오는 동안에도 선택칸에 대한민국을 표시한다.
- 전체 목록을 받은 뒤 대한민국은 한 번만 표시하고, 다른 국가의 선택과 해당 국가 도시 검색을 유지한다.
- 국가를 변경하면 이전 도시 선택은 지운다.

## 검증
- 첫 화면의 대한민국 표시, 다른 나라 선택과 도시 목록 범위, 국가 변경 시 도시 초기화를 확인한다.
- 타입 검사, 관련 테스트, 빌드를 실행한다.

## 상태
- 구현과 로컬 검증 완료. 참가자 화면 확인 전.

## 검증 결과 (2026-09-28)
- 로컬 화면에서 초기 선택값 대한민국, 미국으로 변경, 다시 대한민국으로 변경을 확인했다.
- 독립 테스트에서 최초 렌더의 대한민국 표시와 전체 국가 목록의 중복·다른 국가 제공을 확인했다. 도시 초기화 코드는 기존 로직을 그대로 유지했고 별도의 화면 입력 시험은 하지 않았다.
- `npm run check`: 타입 검사와 전체 194개 테스트 통과. `npm run build` 통과.
