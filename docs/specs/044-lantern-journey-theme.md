# 길을 비추는 등불 테마

## 요구사항
- 사용자가 선택한 C안의 산·빛의 길·등불 이미지를 첫 화면에 적용한다.
- 제목과 시작 버튼은 이미지와 분리된 실제 텍스트/링크로 제공한다. 모바일에서도 가독성과 등불 구도가 유지된다.
- 관련 결과 페이지의 탐색, 한줄평, 공유 카드와 그래프 강조 색을 남색·금빛·밝은 종이 바탕으로 통일한다. 이용자에게 보이는 도령 명칭과 말투를 등불의 안내 문구로 바꾼다.
- 기존 사주 계산과 원국 기반 한줄평 근거, 저장·공유의 개인정보 제외 정책을 유지한다.
- v0.3.0으로 버전을 기록하고 PR 병합, main 태그와 Vercel 운영 배포를 진행한다.

## 구현 계획
- 승인된 이미지의 원본은 유지하고 public/images/lantern-journey.webp로 웹 최적화한다.
- 첫 화면에 제목·설명·출생 입력 링크, 간결한 안내를 배치한다. 이미지 장식은 스크린리더에서 제외한다.
- 도령의 한줄평 → 내 길을 비추는 한마디. 결과 탐색과 공유 카드에 등불 모티프를 연결한다.
