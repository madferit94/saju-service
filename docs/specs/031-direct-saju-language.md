# 사주 풀이를 먼저 보여주는 결과 문장

## 요청
- 결과 화면의 `판정 보류`처럼 계산 상태를 앞세운 표현을 없앤다.
- 확인된 사주 구조와 대운의 관계를 이용자가 이해할 수 있는 문장으로 풀이한다.

## 구현 기준
- 인생 그래프에서 도움 오행을 정하기 어려운 원국은 합·충·반복의 변화가 두드러진 시기를 설명한다.
- 심층 분석 카드에는 강약·용신의 내부 상태값 대신 관찰된 생조 비중과 계절 오행을 읽기 쉬운 문장으로 표시한다.
- 근거가 없는 전성기, 최종 용신, 좋은 사건을 확정하지 않는다. 내부 계산 상태와 Gemini의 확정 방지 기준은 유지한다.
- 화면을 읽는 보조 기술의 설명도 같은 말투로 바꾼다.

## 검증
- 도움 오행을 정한 원국과 그렇지 않은 원국의 결과를 각각 확인한다.
- 독립 테스트, 타입 검사, 전체 테스트, 빌드를 실행한다.

## 상태
- 구현과 로컬 검증 완료. 참가자 화면 확인 전.

## 검증 결과 (2026-09-28)
- 인생 그래프의 변화 중심 원국과 오행 중심 원국, 심층 분석의 경계·특수 사례를 독립 렌더링 테스트로 확인했다.
- 두 AI 프롬프트가 내부 상태를 본문에 그대로 쓰지 않도록 지시하는 테스트를 확인했다.
- `npm run check`: 타입 검사와 전체 196개 테스트 통과. `npm run build` 통과.
- 로컬 브라우저에 저장된 원국에서 그래프의 `변화가 두드러지는 시기`와 시기별 풀이, 분석 카드의 기운 설명이 표시되는 것을 확인했다. 이 원국은 내부 계산상 특수 사례이며, 본문에 `판정 보류`가 보이지 않는다.
- AI가 새로 생성할 실제 문장의 품질은 외부 호출을 하지 않아 아직 확인하지 않았다.
