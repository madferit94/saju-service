# 별이 흐르는 밤하늘 화면과 읽기 개선

## 요청
- 첫 화면은 밤하늘과 별똥별을 떠올리게 한다.
- 긴 사주 풀이와 입력 폼은 글자가 또렷하고 구획을 쉽게 구별할 수 있어야 한다.

## 구현 기준
- 짙은 남색 배경에 장식용 별과 간헐적 빛줄기를 CSS로 만든다. 별은 내용·조작 요소를 가리지 않는다.
- 본문은 불투명하고 밝은 카드와 진한 글자, 충분한 행간으로 유지한다.
- 좁은 화면에서도 글과 버튼을 읽고 누를 수 있게 한다. 움직임 감소 설정에서는 빛줄기 애니메이션을 중단한다.

## 검증
- 입력 화면과 계산 결과의 데스크톱·모바일 화면, 대비, 키보드 초점, 움직임 감소를 확인한다.
- 타입 검사, 전체 테스트, 빌드를 통과한다.

## 상태
- 구현과 로컬 검증 완료. 참가자 화면 확인 전.

## 검증 결과 (2026-09-28)
- 로컬 브라우저에서 첫 화면의 남색 별 배경·달, 읽기 카드, 그래프 영역을 확인했다.
- 375px 모바일 폭에서 문서 가로 넘침이 없음을 확인했다. 움직임 감소 설정은 CSS 규칙으로 애니메이션 중단을 확인했고 설정을 바꾼 실제 화면은 확인하지 못했다.
- `npm run check`: 타입 검사와 전체 190개 테스트 통과. `npm run build` 통과.
