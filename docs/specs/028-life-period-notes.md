# 인생 그래프 시기별 경험 한 줄 메모

## 요청
- 그래프의 시기별 사주 풀이 옆에 이용자가 실제 경험을 직접 한 줄 적고 다시 읽는다.
- 자유 대화형 AI 기능은 포함하지 않는다.

## 구현 기준
- 각 대운 구간에 메모 한 줄을 입력·저장·수정·삭제할 수 있다. 지난 시기는 경험, 미래 시기는 생각이나 계획을 적는다. 빈 메모는 저장하지 않는다.
- 메모는 출생 입력과 대운 진행 방향을 묶은 식별자 아래 현재 브라우저에만 보관한다. 계정 저장, 서버, AI에 전송하지 않는다.
- 저장 실패를 알리고 성공했다고 표시하지 않는다. 다른 사주를 열면 그 사주의 메모만 보여준다.
- 시기별 상세 근거를 닫아도 메모한 구간은 찾아볼 수 있다.

## 검증
- 저장·수정·삭제, 새로고침 복원, 다른 사주 분리, 저장 공간 실패, 빈 입력, 한 줄 길이 제한을 확인한다.
- 타입 검사, 전체 테스트, 빌드를 통과한다.

## 상태
- 구현과 로컬 검증 완료. 참가자 화면 확인 전.

## 검증 결과 (2026-09-28)
- 독립 테스트에서 사주·대운 방향별 분리, 저장·수정·삭제·복원, 빈 값·길이 제한, 손상된 자료와 저장 실패를 확인했다.
- 로컬 브라우저에서 메모 펼침, 시험용 메모 저장·새로고침 복원·삭제를 확인했다. 시험용 메모는 삭제했다.
- `npm run check`: 타입 검사와 전체 190개 테스트 통과. `npm run build` 통과.
