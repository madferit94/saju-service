# 쉬운 말과 계산 근거에 맞는 Gemini 사주 풀이

## 요청
- 조사 문서 `docs/research/2026-09-29-prompt-quality-v01.md`의 초안을 실제 선택형 Gemini 종합 해석에 적용한다.
- 사주 결과의 품질을 높일 방법을 확인한다. 계산 일치, 개인별 설명, 읽기 쉬움과 생성 시간·비용을 구분해 평가한다.

## 구현 기준
- 코드가 계산한 원국·대운·세운·월운만 해석 자료로 사용한다. 모델에게 새로운 간지나 개인 사건을 계산·추정하게 하지 않는다.
- 공통 지시는 간결한 역할·근거 제한·쉬운 글쓰기 규칙으로 정리한다. 계산 자료와 이번 과제는 분리된 구획으로 제시한다.
- 첫 생활 문장은 전문 용어 없이 시작하고, 필요한 근거를 그 뒤에 짧게 설명한다. 도령의 차분한 존댓말을 유지한다.
- 대운/세운/월운의 정확한 구분, 12개월과 모든 대운 항목, 초년·청년·중년·후반, 미성년 배려, 근거 없는 건강·금전·관계 예언 금지를 유지한다.
- 현재 JSON 응답 형식·검증·저장 구조는 유지한다. 기존 저장 해석은 지우거나 자동 재생성하지 않는다.
- Gemini 3 계열의 권장 기본 샘플링 설정을 가상 자료에서 시험한다. 개선을 실제로 확인하기 전에는 정확도 향상을 단정하지 않는다.
- 코드가 직접 만드는 생활 운 등은 이번 AI 프롬프트 변경과 별개이며 범위를 혼동하지 않는다.

## 검증
- 독립 서브에이전트가 새 프롬프트의 구조, 개인정보 제외, 정확한 층위와 형식 조건을 시험한다.
- 전체 타입 검사·테스트·빌드와 기존 계산·저장 경로를 확인한다.
- 가능하면 같은 가상 입력의 이전·새 프롬프트 실제 Gemini 응답을 비교한다. 실패 또는 미실행은 그대로 기록한다.

## 상태
- 구현 완료. 참가자 화면 확인 전.
- 공통 지시를 계산 근거 제한·쉬운 말·해석 범위 중심으로 다시 구성하고, 종합 해석 요청의 자료와 과제를 구획으로 분리했다. 기존 JSON 응답·저장 형식은 유지했다.
- 도입 문장의 전문어를 검사하고, 생성 결과가 검증에 걸리면 기존 초안을 포함해 한 번 다시 쓰도록 했다. 전체 항목의 첫 두 문장까지 기계적으로 차단하면 실제 가상 미성년 사례가 두 번 실패해 502가 발생했으므로, 자동 차단은 종합 첫 문장으로 좁혔다. 다른 항목의 쉬운 말은 프롬프트로 유도하며 사람 평가가 필요하다.
- 독립 테스트를 포함한 전체 212개 테스트·타입 검사·배포용 빌드 통과. 가상 성인과 미성년 입력의 실제 Gemini API 응답에서 12개월·11개 대운·첫 문장 생성 성공. 실제 사용자의 사주와 화면은 참가자 확인 전이다.
- 응답 시간·비용 또는 사주 계산 정확도가 개선됐다는 결론은 내리지 않는다. 비교와 다음 개선 순서는 `docs/research/2026-09-29-prompt-evaluation-v01.md`에 기록했다.
