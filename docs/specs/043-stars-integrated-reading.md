# 귀인·신살 상세와 종합 해석

## 범위
- 기존 천을·태극·문창·월덕귀인에 천덕귀인, 역마살, 도화살(함지), 화개살, 양인살, 건록을 추가한다. 건록은 신살 참고 표지이며 월지 건록격 확정과 구별한다.
- 기존 네 귀인 저장 형식은 유지하고, 새 목록은 원국에서 다시 계산한다. 상세에는 뜻, 적용 기준과 위치, 내 원국의 강약/계절 조건, 살릴 점·부담·생활 실천을 표시한다.
- 만세력의 해당 이름과 목록 카드는 키보드로 누를 수 있다. 선택한 항목 하나의 설명을 같은 영역에 표시한다. 기존 '계산 근거 접기' 창을 되살리지 않는다.
- 종합 해석은 원국→강약·월령·뿌리→대운·세운·월운→귀인·신살의 순서로 판단한다. 별의 개수를 점수로 합산하지 않고, 신살로 단독 사건·질병·혼인 결과를 단정하지 않는다.
- 현재 대운/선택 세운의 일치를 원국 일치와 별도로 표시한다. 기준은 출생 원국에 고정하며 운의 글자만 대조한다. 역마·도화·화개는 년지 기준과 일지 보조 기준을 구별하며 기준 자리 자체는 원국 매칭 대상에서 제외한다. 합쳐진 표지는 위치를 중복 표시하지 않는다.
- AI 입력과 상담 근거에 일치 결과 및 원국과 연결된 해석을 포함한다. 새 전체 응답은 신살 종합 항목에서 원국에 실제 있는 표지 ID를 반환해야 한다. 미해당 표지를 보유했다고 쓰면 오류로 처리한다. 기존 저장 해석은 호환한다.

## 명시적 규칙
- 천덕: 월지 寅卯辰巳午未申酉戌亥子丑 → 丁申壬辛亥甲癸寅丙乙巳庚. 천간/지지 대상을 구분한다. 사중월은 《연해자평》의 坤申·乾亥·艮寅·巽巳 해석을 채택하며 다른 판본 차이는 상세에 표시한다.
- 삼합 기준 申子辰 / 寅午戌 / 巳酉丑 / 亥卯未: 역마 寅申亥巳, 도화 酉卯午子, 화개 辰戌丑未.
- 양인: 양간 甲丙戊庚壬 → 卯午午酉子, 음간은 '선택한 규칙의 판정 대상 아님'.
- 건록: 甲乙丙丁戊己庚辛壬癸 → 寅卯巳午巳午申酉亥子.
- 기존 문창·태극 규칙은 Spec003을 그대로 유지한다.
