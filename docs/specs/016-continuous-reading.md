# 끊김 없이 읽는 사주 결과

## 요청과 현재 상태
- 출생 정보를 계산하면 로컬 풀이를 바로 읽고, Gemini 정보 전송에 동의하면 별도의 ‘8장 상담 시작’ 버튼 없이 깊은 풀이가 자동으로 이어서 작성된다.
- 내부 8장 구분은 API 검증·부분 저장·재개를 위해 유지한다. 화면에서는 장을 접어두거나 시작 버튼을 요구하지 않고 한 편의 긴 상담처럼 차례대로 펼친다.
- 이용자는 운 항목의 부족 여부도 점검해 달라고 했다. 이번 범위는 항목 추가 전 현황 확인과 읽기 흐름 개선이다.

## 항목 현황과 후속 후보
- 구현: 평생 흐름, 대운, 세운/연운, 절입 월운, 일진 간지 달력, 오행·귀인·십성·지장간·합충 일부, 일/학업·재물·관계의 종합 풀이.
- 독립 풀이가 없는 항목: 하루의 운(일진은 간지만 표시), 시운, 학업·시험, 가족·자녀, 연애·결혼, 이동·이사, 건강. 신살은 귀인 4종만, 관계 계산은 천간합·지지육합·충·반복까지만 한다. 향후 항목별 계산 근거와 표현 범위를 정한 뒤 추가한다.

## 화면과 동작
1. 출생 정보 계산 후 로컬 풀이의 본문은 바로 펼쳐진다. 전문 계산 근거만 필요할 때 펼치는 방식은 유지한다.
2. 별도 정보 전송 동의를 체크하는 순간, 유효한 결과와 미완성 상담이 있으면 Gemini 상담 생성을 한 번 시작한다. 체크 해제나 다른 결과/계정으로 이동하면 진행 중인 요청을 취소한다.
3. 같은 연도·문체의 완성 상담이 이미 있으면 다시 호출하지 않고 기존 결과를 보여준다. 미완성 상담은 남은 장부터 이어 쓴다. 실패 시 완성된 내용은 유지하고 다시 시도할 수 있다. 자동 무한 재시도는 하지 않는다.
4. 상담은 완성된 장부터 순서대로 화면에 추가하며 기본적으로 모두 보인다. 목차는 위치 이동용이다. 생성 진행·중단·오류·재시도는 알아보기 쉬운 말로 표시한다.
5. 기존 짧은 Gemini 종합 해석과 저장본은 호환된다. 추가 생성 기능은 보조 영역에 둔다. 계정에서 연 결과를 기기에 자동 저장하지 않는다.
6. 미성년자용 배움·생활·가족 카드에는 성인용 AI 일·돈·관계 문장을 순서만으로 끼워 넣지 않는다. 해당 카드의 나이별 로컬 풀이를 유지한다.

## 실패와 검증
- 동의 전 Gemini 호출 없음. 결과 없음·유효하지 않은 입력에는 호출 없음. 반복 렌더와 완성본 재열기에서 중복 호출 없음.
- 동의 후 요청 중단/계정 교체/새 출생 입력의 늦은 응답은 현재 결과를 덮지 않는다.
- 전체 타입·테스트·빌드와 화면에서 로컬 본문·상담 연속 노출을 확인한다. Gemini 실호출은 가상 자료로만 확인하며 API 비용을 불필요하게 발생시키지 않는다.

## 상태
구현 및 자동 검증 완료. 참가자 화면 확인 전.

- 전체 테스트 161개, 타입 검사, 빌드 통과. 동의 전 무호출·동의 직후 생성·완성본 중복 방지·중단 후 재시도·연속 본문·나이별 풀이 대응을 가상 자료로 확인했다.
- 개발 서버 HTTP 200 확인. 실제 Gemini 계정으로 8개 주제를 끝까지 생성하는 검증은 수행하지 않았다. 사용자의 API 사용량과 실제 출생 자료를 쓰는 화면 확인은 참가자에게 남아 있다.
