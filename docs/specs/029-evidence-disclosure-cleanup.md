# 결과 화면의 근거 접기 창 정리와 프롬프트 대안 탐색

## 이용자 요청

- 결과 화면에서 모든 계산 근거·판정 기준 접기 창을 없애 가독성을 높인다. 대운·월운·4계절 본문, 경험 메모, 선택형 Gemini 생성처럼 실제 내용을 여닫는 기능은 유지한다.
- 현재 Gemini 프롬프트를 교체하기 전에 공식 자료에서 다른 설계 방식을 탐색한다. 이번 작업은 대안을 비교하며 프롬프트 코드와 모델은 바꾸지 않는다.

## 화면 기준

- 그래프·4계절·만세력·강약/격국/용신·평생운·세운/월운·생활운·오늘의 운세·8장 상담의 반복적인 근거 `<details>`를 제거한다.
- 이미 보이는 개인별 해석 문장, 현재 계절의 이유·개운법, 대운의 핵심 관계와 부담, 해석의 한계 안내는 유지한다. 원국 계산과 Gemini에 전달하는 구조화 근거 데이터는 유지한다.
- `AI 종합 해석 더 읽기`처럼 근거가 아닌 추가 풀이 접기는 유지한다.

## 프롬프트 대안 조사

현재 공통 프롬프트는 CO-STAR와 다수의 반복 제약을 한 요청에 붙인다. Spec 018의 가상 Gemini 응답에서는 상투적 원국 문장이 남아 있어 단순히 규칙을 더 추가하는 방식은 근거가 약하다.

1. **짧은 공통 원칙 + 장별 과제**: 불변인 개인정보·단정 금지·계산 근거 제약만 앞에 두고, 평생운/월운 등에서 필요한 구체적 지시만 붙인다. Google의 Gemini 3 가이드는 명확하고 직접적인 지시, 일관된 구획, 과도하게 장황한 구형 프롬프트의 재검토를 권한다. 출처: https://ai.google.dev/gemini-api/docs/prompting-strategies 및 https://ai.google.dev/gemini-api/docs/gemini-3
2. **다양한 소수 예시**: 실제 이용자의 사주가 아닌 가상 원국을 써서 좋은 풀이·상투적인 풀이·판정 보류 풀이를 같은 형식으로 보여 준다. Google과 Anthropic은 예시가 문체와 형식을 조정할 수 있고, 다양성과 일관성이 중요하다고 설명한다. 출처: https://ai.google.dev/gemini-api/docs/prompting-strategies 및 https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/prompt-templates-and-variables
3. **자료/지시 분리 + 구조화 응답 검증**: `<calculated_context>`처럼 계산 자료와 작성 지시를 분리하고, JSON Schema와 코드 검증을 유지한다. 구조화 출력만으로 내용의 사실성이 보장되지는 않는다. 출처: https://ai.google.dev/gemini-api/docs/prompting-strategies 및 https://ai.google.dev/gemini-api/docs/structured-output

권장 다음 실험은 1+2를 결합한 후보를 현재 프롬프트와 같은 가상 원국 세트로 비교하는 것이다. 월운/대운 간지 혼동, 근거 없는 사건, 반복 문장, 생활 언어와 계산 근거 연결을 평가하고 실제 Gemini 응답을 확인한 후에만 교체한다. 위 가이드가 사주 풀이의 정확성을 보증한다는 뜻은 아니다.

## 검증

- 결과 화면의 근거 접기 창 제거, 핵심 해석·한계 문장 보존, 일반 콘텐츠 접기 유지 여부를 렌더링 테스트와 브라우저에서 확인한다.
- 전체 테스트, 타입 검사, 빌드 및 기존 사주 계산·저장 동작을 확인한다.

구현과 검증 완료. 프롬프트 후보는 조사만 했고 기존 Gemini 프롬프트는 유지한다.

- Gemini 프롬프트 코드는 변경하지 않았고 후보 대안은 위 공식 자료를 바탕으로 정리했다.
