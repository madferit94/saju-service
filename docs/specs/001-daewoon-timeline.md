# 001 개인별 대운 흐름

## 목적

출생 정보를 입력한 이용자가 자신의 대운을 과거 → 현재 → 미래 순서로 읽는다. 이번 구현은 계산 결과와 시간표를 보여주는 첫 조각이다. AI 해석, 저장 링크, 궁합은 뒤의 기능으로 이어간다.

## 입력과 계산

- 기존 양력 생년월일·출생 시각 입력을 사용한다. 기존 지원 범위(1990년 이후, 출생 시각 필수)는 이번 단계에서 유지한다.
- 대운의 진행 방향을 결정하는 입력을 추가한다. 현재 화면은 남성식/여성식 중 직접 선택하는 방식이다. 이 표현은 참가자 확인 전이며 요청에 따라 조정한다.
- 기존 `lunar-javascript@1.7.7`의 `getYun`과 `getDaYun`을 사용한다. 출생지를 선택하면 해당 지역 시간대의 출생 순간을 절기 계산에 반영한다. 출생지 기능 이전의 기준 사례는 한국 시각으로 검사했다.
- 출생 후 첫 대운이 시작되기 전은 `대운 시작 전`으로 구분한다. 각 대운은 간지, 시작·끝 연도와 나이를 보여준다.
- 오늘 날짜를 기준으로 지나간 시기, 현재 시기, 앞으로의 시기를 구분한다. 미래 사건을 단정하는 문장은 만들지 않는다.

## 완료 조건

1. 정상 입력에 대해 출생 시기부터 앞으로의 대운이 연도순으로 나타난다.
2. 현재 시기 카드가 텍스트와 모양으로 구별된다. 색만으로 구별하지 않는다.
3. 입력 오류에는 기존 안내를 유지하며 잘못된 결과를 표시하지 않는다.
4. 좁은 휴대전화 화면에서도 가로 스크롤 없이 읽을 수 있다.
5. 계산 기준 사례와 입력 오류를 자동 검사하고, 실제 화면에서 결과를 확인한다.

## 검증 결과

- `npm run check`의 타입 검사와 자동 테스트 21개가 통과했다. 한국 시각 입춘 경계에서 사주 년주와 대운 방향·간지가 함께 바뀌는지도 검사했다.
- 예시 입력 `2005-12-23 08:37`, 남성식에서 과거·현재·미래 구간이 화면에 나타나는 것을 확인했다.
- 375px 휴대전화 너비에서 문서 가로 넘침이 없는 것을 확인했다.
- 참가자 화면 확인 전. 계산 방식 선택 문구도 참가자 확인 전이므로 진행 상태는 미완료로 둔다.
