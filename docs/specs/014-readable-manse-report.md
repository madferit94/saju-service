# 쉬운 8장 상담과 만세력 결과 화면

## 요청과 방향
- 첨부 PDF의 정보 순서와 표·오행 색상·도표 구성을 참고한다. 개인 정보, 원본 PDF, 캐릭터와 타사 브랜드는 저장소에 포함하지 않는다.
- 흰 바탕, 따뜻한 회색 선, 절제된 오행 색, 한글 우선의 네 기둥 표. 결과 목차에서 바로 이동한다.
- 상담의 깊이는 유지하고 생활 설명을 먼저 읽게 한다. 전문 근거는 접어서 제공한다.

## 화면
1. 시주·일주·월주·년주 순서의 만세력 표: 천간/지지의 한글+한자, 오행, 십성, 지장간, 12운성. 기존 계산 원국을 그대로 사용한다.
2. 기존 4종 귀인을 자리별로 표시, 전체 규칙은 펼쳐 보기.
3. 오행 및 십성 8글자 비율을 도넛과 수치 목록으로 함께 표시. 지지는 본기 기준, 일간은 비견에 포함. 이 단순 분포와 강약 가중값을 구분한다.
4. 강약·격국·용신은 쉬운 제목과 설명, 상세 계산은 펼쳐 보기.
5. 대운·선택 연도 주변 연운·12절입 월운 카드와 일진 달력. 선택 연도 연동, 달력 월 이동. 일진은 선택 날짜 정오 기준의 간지이며 출생지 시각 보정이나 길일 판정이 아니다.
6. 기존 평생운·주제별 해석·저장·로그인·상담 생성 유지. 작은 화면에서 표/시간표 안만 가로 스크롤 가능, 화면 전체 넘침 방지.

## 쉬운 상담
- 8장과 3~4절, 서로 다른 계산 근거 2개 이상, 반대 조건/생활 예시/확인 질문/행동은 유지한다.
- 각 장 30~180자의 쉬운 요약 추가. 본문은 생활 상황 → 개인별 이유 → 선택 순서, 최소280자·2문단. 전문 용어의 연속 나열 금지, 필요하면 바로 일상말로 풀이. 한자 독음 병기. 요약과 각 절 첫 문장의 핵심 전문용어를 검사하되 문장 끝 동사만으로 정상 생활 설명을 거부하지 않는다.
- 화면에는 쉬운 장 제목과 요약, 본문·예시·실천·질문 먼저 표시. 반대 조건과 원자료는 별도 펼침.
- 선택적 readingStyleVersion:2 및 chapter.summary 추가. 이전 저장본도 읽는다. 이전 방식은 표시하고 새 방식 작성 버튼을 제공한다. 생성은 사용자 동의 후에만 시작하며 첫 성공 전 기존 자료를 유지한다. 새 방식 장은 요약 검증까지 통과해야 저장한다.
- 기존 계산/개인정보 정책 유지, 모델 gemini-3.5-flash-lite 유지.

## 이번 제외
- PDF의 미지원 신살 전체 추가, 합화에 따른 오행 재배정, 타사 강약 분포/인구 백분율 복제, 타사 산출값 일치 보장.
- 자유 대화와 자동 유료 생성. PDF의 실제 개인 자료로 외부 AI 검사하지 않는다.

## 검증 계획
- 독립 테스트: 표 순서·원국 일치·분포 합계·십성/12운성·달력 윤년과 월 경계, 이전 저장 호환/새 요약 검증/다시 작성 시 요청 경합.
- 타입검사·전체 테스트·빌드. 가상 자료로 API와 PC/모바일 화면 확인. GitHub 브랜치 커밋·푸시·PR·검증 후 main 병합.

## 상태
구현·자동 검증 완료. 참가자 확인 전.
- 기존 계산 원국 유지, 시·일·월·년 표, 귀인 4종, 대표8자 오행·십성 비율, 12운성, 연동 운 시간표와 일진 달력 구현.
- 쉬운 장 제목, 요약, 문단·예시·실천·질문 순서와 접힌 근거. 이전 상담 호환, 새 문체 재작성/부분 저장/실패 보존 구현.
- 독립 담당이 신규18개를 추가하여 전체136개 및 타입검사 통과, 프로덕션 빌드 통과. 12운성120조합 라이브러리 대조, 월 경계·윤년, 재작성·중단·지연응답 경합 포함.
- 375px/1280px 화면에서 사주 표와 도표·상담 레이아웃, 문서 전체 가로 넘침 없음 확인. 가상 생성본으로 상담 요약·본문 렌더링 확인.
- 실제 Gemini 가상 자료로 원국·강약·격국/용신 3장9절 성공(각 본문289~439자). 초기 짧은 설명과 어려운 요약, 과도한 문장끝 검증을 발견하여 스키마·편집 재시도·검증 보완. 직접 호출과 개발 서버의 응답 차이는 서버 재시작 후 최신 코드로 재검증하여 HTTP200 확인.
- 요약/분량/근거 ID 검증은 모든 풀이의 의미 정확성이나 독자의 이해를 보장하지 않는다. 새 문체로 8장 전체 실생성 및 참가자 본인의 최종 읽기 확인은 아직 수행하지 않았다.
