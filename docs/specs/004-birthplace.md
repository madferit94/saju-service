# 004 해외 출생지 반영

## 목적

출생 국가·도시를 선택하고, 해당 도시의 시간대와 경도를 사주 및 대운 계산에 실제로 반영한다.

## 계산 기준

- 약 4만 도시가 들어 있는 로컬 도시 자료에서 국가와 도시를 선택한다. 목록에 없는 도시는 이번 버전에서 계산하지 않는다.
- 입력 시각은 도시의 IANA 시간대 규칙을 적용한다. 일광절약시간 때문에 존재하지 않거나 두 번 나타나는 시각은 임의로 고르지 않고 오류를 표시한다.
- 년·월주와 절기 및 대운 시작은 출생 순간을 중국 표준시(UTC+8)로 바꿔 기존 계산 엔진에 전달한다.
- 일·시주는 출생 순간의 UTC에 도시 경도 × 4분을 더한 지방평균시를 사용한다. 균시차까지 반영한 진태양시는 아니다.
- 계산 결과에 국가·도시·시간대·경도 및 적용 기준을 표시한다.
- 도시 검색은 이 앱 서버의 로컬 자료에서 수행한다. 출생 날짜·시각은 검색 요청에 넣지 않는다.

## 참고 자료

- 도시 좌표·시간대 목록: https://github.com/coroboros/location-timezone
- 역사적 시간대 자료: https://www.iana.org/time-zones
- 중복되거나 없는 현지 시각 처리: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal/ZonedDateTime
- 경도 1도당 평균 태양시 약 4분과 균시차의 차이: https://aa.usno.navy.mil/faq/eqtime

## 완료 조건

1. 한국과 해외 도시를 선택할 수 있다.
2. 같은 현지 시각이라도 도시의 시간대·경도가 다르면 경계 근처에서 계산 결과가 달라질 수 있다.
3. 일광절약시간 경계 입력을 조용히 잘못 계산하지 않는다.
4. 기존 계산 테스트와 새 출생지 테스트를 통과하고 화면을 확인한다.

## 검증 결과

- 한국·뉴욕의 시간대와 경도 차이, 입춘·23시 경계, 일광절약시간의 없는/중복 시각, 도시 검색을 테스트했다. `npm run check` 33개 통과.
- 배포용 빌드가 통과했고, 브라우저에서 서울·뉴욕 도시 선택과 뉴욕 시간대·경도 표기를 확인했다. 참가자 화면 확인 전.
