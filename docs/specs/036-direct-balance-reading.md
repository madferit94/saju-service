# 균형·도움 화면의 직접적인 사주 풀이

## 요청
- 균형·도움 화면의 추상적이고 중립적인 설명을 없애고 사주를 읽는 문장으로 바꾼다.
- “성격이나 건강의 강약이 아닙니다. 이 수치는 서비스의 비교 지표이며 확률이나 공인 점수가 아닙니다” 같은 반복 안내를 결과 본문에서 제거한다.

## 구현 기준
- 세 카드가 태어난 계절과 일간의 관계, 월지에서 읽히는 십성 주제, 실제 오행의 쓰임을 각각 설명한다.
- 원국에 계산되지 않은 간지·용신·개인 사건은 꾸미지 않는다. 건강 상태나 미래 결과를 단정하지 않는다.
- 계산의 예외와 내부 상태값은 코드에 남기되 화면에는 `판정 보류`, `조건부 후보`, `확률`, `공인 점수`, `확정은 아닙니다` 같은 상태·면책 문장을 반복하지 않는다.
- 주변 결과 화면에도 풀이를 가로막는 중복 주석을 정리하고, 전송 동의·개인정보·입력 오류 안내는 유지한다.
- 기존 사주 계산, 대운, 저장 형식은 바꾸지 않는다.

## 검증
- 서로 다른 계절·강약 배치의 가상 원국에서 카드 문장이 달라지고 계산 근거와 일치하는지 확인한다.
- 독립 서브에이전트가 관련 테스트를 작성·실행하고, 주 에이전트가 전체 검사·빌드와 로컬 화면을 확인한다.

## 상태
- 구현 완료. 참가자 화면 확인 전.
- 균형·도움 카드에 실제 일간, 월주 계절, 십성, 도움 오행을 연결한 문장을 표시한다. 내부 강약 점수나 보류 상태는 계산에 남기고 결과 본문에서는 숨겼다.
- 사주표·오행·십성·오늘의 운세·인생 그래프·생활 운에서 반복되던 면책성 문장을 정리했다. AI 전송 동의와 개인정보 안내는 유지했다.
- 독립 담당자가 가상 원국별 문장과 조사를 검증했다. 관련 테스트 19개 통과, 전체 214개 테스트·타입 검사·배포용 빌드 통과. 로컬 균형·도움 화면에서 변경 문장을 확인했다.
- 실제 이용자의 체감 품질은 참가자 확인 전. 기존에 저장된 AI 해석 문장은 자동으로 다시 쓰지 않는다.
