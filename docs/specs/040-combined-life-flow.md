# 인생 그래프와 현재 계절의 조합 해석

## 요구와 계산 규칙
- 그래프는 단일 선을 유지한다. 도움 오행 두 글자 일치 개수를 원국 생조 비중의 균형 변화로 교체한다.
- 원국 가중 기여에 운 천간 10, 지지 지장간 15(본/중/여기 60/30/10, 두 글자는 70/30, 하나는 100%)를 같은 월령 계수로 추가해 50%와의 거리 감소를 비교한다. 이것은 전통의 공인 점수나 확률이 아닌 명시된 서비스 비교 규칙이다.
- 모든 원국에서 높이의 의미는 균형 보완 정도로 일치한다. 민감/특수 원국은 확정적인 전성기 후보를 만들지 않는다. 조후·뿌리·투간은 설명에 포함하고 숫자에 임의 가산하지 않는다.
- 최고점과 비교한 차이가 작은 시기를 한 묶음으로 다루고, 전 구간이 비슷하면 전성기를 억지 선정하지 않는다. 동점은 숨기지 않으며 강조는 최대 두 구간이다.
- 4계절은 대운 천간과 모든 지장간의 십성 비중으로 주제를 정하고 원국의 배치와 조합해 이유·개운법을 설명한다. 현재 카드에는 해당 연도 세운이 주는 별도 주제와 실천을 덧붙인다. 연운이 대운의 계절을 강제로 뒤집지 않는다.
- 그래프와 계절은 독립 영역이며 같은 점수를 사용하지 않는다. 메모와 연령 보호를 유지한다.
## 검증
- 다양한/동점/민감/특수 원국, 대운 경계·시작 전, 합충 개수로 그래프가 높아지지 않는지 검증한다.
- 계절의 연도 변화·연령 보호·근거 연결·화면 접근성·메모 회귀를 독립 테스트한다.
