# 생활 주제별 운 풀이 확장

## 요청과 현황
- 사용자는 건강, 연애, 배우자, 자녀를 포함해 빠진 운을 찾아 결과 화면에서 직접 읽고 싶다.
- 현재 성인 카드 3개는 일·학업, 재물, 관계를 합쳐 보여준다. 미성년 카드 3개는 배움, 생활, 가족·또래다. 평생운·대운·세운·월운과 일진 간지는 별도로 존재한다.
- 별도 풀이가 없는 성인 주제: 건강, 연애, 배우자, 자녀, 가족·부모, 친구·협업, 학업·시험, 이동·주거, 사업·사회 역할.

## 범위
1. 성인 결과에 직업, 학업·시험, 재물, 사업·활동, 연애, 배우자·동반자, 자녀·다음 세대, 가족·부모, 친구·협업, 건강·생활 균형, 이동·주거를 별도 카드로 제공한다.
2. 각 카드에는 네 기둥의 해당 자리, 십성·지장간, 선택 연도의 세운 및 대운과 합충 등 확인 가능한 근거를 연결한다. 해석에는 활용점, 부담, 현실에서 확인할 질문을 포함한다. 원국의 한 자리나 십성 한 개로 사건을 확정하지 않는다.
3. 미성년 결과에는 배움·가족·또래·생활 균형·적응을 중심으로 보여주며 혼인, 임신, 투자, 직장, 사업 예언을 하지 않는다.
4. 건강에서는 오행으로 질병·수명·임신 가능성을 판단하지 않는다. 생활 부담을 돌아보는 질문과 필요한 경우 전문 상담 권유 정도로 한정한다. 배우자/자녀가 반드시 있거나 있어야 한다고 가정하지 않는다.
5. 기존 저장 결과 형식과 Gemini 요약 해석은 유지한다. 주제별 카드는 계산된 로컬 결과이므로 Gemini 동의나 추가 호출이 필요 없다.
6. 일진의 독립적 하루 풀이, 시운, 각종 신살의 전수 계산, 실제 사건 발생 연도 확정은 이번 범위에서 제외하고 현황에 남긴다.
7. 이용자가 불필요하다고 지적한 ‘이어서 읽는 나의 깊은 풀이’의 자동 8주제 생성·진행 영역은 결과 화면에서 제거한다. 기존에 저장된 상담 자료와 API 형식은 삭제하지 않는다. 짧은 Gemini 종합 해석은 별도로 펼쳐 동의하고 버튼을 누를 때만 생성한다.

## 검증
- 주요 카드가 가상 성인 사주에서 모두 나오고, 서로 다른 원국·선택 연도에서 근거와 풀이가 달라지는지 확인한다.
- 미성년 결과에 연애·배우자·자녀·직장·투자 예언이 나타나지 않는지 확인한다.
- 근거 링크와 화면 표시, 타입·전체 테스트·빌드를 확인한다.
- 동의만으로 Gemini API를 호출하지 않고, 명시적 버튼에서만 종합 해석을 요청하는지 확인한다.

## 상태
구현 및 자동 검증 완료. 참가자 화면 확인 전.

- 가상 성인 사주에서 11개, 미성년 사주에서 5개 생활 운과 각 카드의 계산 근거·경험 질문 확인.
- 다른 원국과 선택 연도에서 풀이가 달라지는지 확인. 동의만으로 Gemini를 호출하지 않고 별도 버튼을 누를 때만 호출하는 화면 테스트 통과.
- 독립 테스트 담당 1명이 관련 테스트를 작성·실행했고, 전체 테스트 158개와 타입 검사·빌드가 통과했다. 개발 서버 HTTP 200 확인. 실제 개인 결과 화면과 Gemini 실호출은 참가자 확인 전.
