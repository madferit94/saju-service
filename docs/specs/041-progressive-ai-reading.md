# 핵심부터 표시하는 AI 풀이

## 요구와 응답
- 기존 단일 제출과 로컬 풀이 즉시 표시를 유지한다.
- 짧은 AI 요약을 별도 단계로 먼저 생성·검증해 표시한 뒤 기존 전체 풀이를 요청한다. 요약은 종합·현재 흐름·실천 세 필드와 계산 자료의 근거 ID를 반환한다.
- 요약이 실패해도 전체 풀이를 진행한다. 전체가 실패하면 성공한 요약과 로컬 결과를 유지한다. 재시도는 성공한 단계를 다시 생성하지 않는다.
- 같은 출생 입력·대운 기준·선택 연도·프롬프트 버전의 성공 응답은 브라우저 세션 메모리에서만 재사용한다. 원문 출생 정보나 해석을 공용 서버 캐시에 보관하지 않는다.
- 새 입력/저장본 열기/연도 변경/로그아웃은 진행 요청을 취소하고 늦게 온 결과가 덮어쓰지 않도록 한다. 서버 요청 취소 신호와 단계별 시간 제한을 전달한다.
- 기존 전체 응답·저장 형식 및 기존 API 기본 동작은 유지한다. 요약은 완성된 전체 풀이로 저장하지 않는다.
- 실패 조건: 잘못된 JSON/필수 항목/근거 ID, 전송 미동의, API 오류·시간 초과. 성공한 것처럼 대체하지 않는다.
## 검증
- 독립 테스트로 요약 선표시, 부분 실패·재시도, 캐시 버전 분리, 연도/입력 변경 시 경합, 이전 API·저장 회귀를 확인한다.
- 가상 자료로 실제 생성의 첫 요약·전체 완료 시간을 기록한다. 첫 요약 5~8초는 목표이며 실측 전 보장하지 않는다.
- 실제 화면 성공·실패·재시도와 타입 검사·전체 테스트·빌드를 확인한다.

### 검증 기록 (2026-09-30)
- 독립 API/세션 테스트 9개 및 클라이언트 경합 테스트 15개 통과. 요약 선표시, 요약 실패 뒤 전체 성공, 전체 실패 뒤 요약 유지, 성공 단계 재사용, 새 입력·저장본·로그아웃·연도 변경 시 취소를 검증했다.
- 전체 246개 테스트, 타입 검사, 배포용 빌드 통과. 기본 전체 API와 기존 저장 형식 회귀 통과.
- 실제 Gemini 모델 `gemini-3.5-flash-lite`, 가상 입력 2000-06-15 12:00 서울 남성식, 2026년 기준: 로컬 dev 서버 로그의 요약 요청 2.2초(첫 컴파일 포함), 이어진 전체 요청 12.7초, 둘 다 HTTP 200. 한 사례의 관측이며 전 사용자 지연시간 개선률이나 운영 P95를 의미하지 않는다. 순차 요청이므로 총 완료에는 두 단계 시간이 모두 든다.
- 실제 로컬 화면에서 사주표 즉시 표시 및 상세 생성 중 핵심 풀이 3항목 선표시를 확인했다.
- 프로덕션 빌드를 로컬에서 실행하고 임시 가상 오류 키로 실패를 유도했다. 오류 안내·재시도 버튼과 사주표 유지를 확인한 뒤 정상 환경으로 서버를 다시 실행해 같은 화면의 재시도로 핵심/상세 풀이 성공을 확인했다. 오류 키는 코드·설정 파일에 저장하지 않았다.
- 기존 전체 풀이 외에 짧은 요청 한 번이 추가된다. 전체 응답 자체의 일정한 가속을 보장하지 않으며, 첫 유용한 풀이까지의 대기와 중복 재요청을 줄인다. 사용자별 성공 결과는 해당 화면 세션 메모리 최대 8건만 보관하며 로그아웃/언마운트에서 지운다.
- 운영 배포·실사용자 부하 측정은 이번 작업에 포함하지 않았다.
