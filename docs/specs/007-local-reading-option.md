# 007 외부 전송 없는 로컬 사주 해석

## 목적

Gemini를 요청하지 않아도 계산된 사주와 대운의 기본 해석을 결과 화면에서 바로 확인할 수 있게 한다.

## 사용자 흐름

1. 출생 정보 제출 후 사주, 오행, 귀인과 대운을 계산한다.
2. 같은 계산값을 이용해 브라우저에서 규칙 기반 해석을 만들고 곧바로 표시한다.
3. 각 대운 카드에서 해당 기간의 주제, 살릴 점, 주의할 점, 조언과 경험 질문을 펼쳐 본다.
4. 삶 전반, 과거·현재·미래, 진로, 관계, 돈과 해석의 한계를 별도 요약 카드에서 읽는다.
5. 원하면 Gemini 전송 동의 후 AI 해석을 추가로 요청한다. 동의하지 않아도 로컬 해석은 볼 수 있다.

## 개인정보 및 표현

- 로컬 해석은 이미 계산된 결과를 사용하며 네트워크 요청을 만들지 않는다.
- Gemini 해석과 시각적으로 구분하고, Gemini 생성 결과인 것처럼 표시하지 않는다.
- 과거 경험과 비교할 질문을 제공하고, 강점과 부담을 함께 설명한다.
- 미래를 확정하지 않으며, 계절 가중치·합충·용신 등 반영하지 않은 사주 요소를 공개한다.
- 저장된 계산 결과를 복원하면 로컬 해석도 다시 계산해 표시한다. 로컬 문구를 별도로 저장하지 않는다.

## 완료 조건

1. 유효한 계산 직후 추가 동의나 Gemini API 키 없이 로컬 해석이 화면에 보인다.
2. 각 대운의 해석은 해당 기간과 계산 근거에 연결되며 펼치기/접기 키보드 조작이 가능하다.
3. 로컬 해석은 과거 비교 질문, 미래의 불확실성, 주의할 점을 포함한다.
4. 로컬 해석을 보여주는 동작은 Gemini API를 호출하지 않으며 Gemini 이용 여부와 분리되어 있다.
5. 저장된 계산 결과를 다시 열어도 로컬 해석을 재구성할 수 있다.
6. 타입 검사와 자동 테스트가 통과하고 화면 표시를 확인한다.

## 상태

완료.

## 구현 및 검증 결과

- `buildLocalReading` 결과를 계산 직후 화면에 표시하며, 모든 대운 카드에 해당 연도·간지·과거/현재/미래 상태별 강점·주의점·조언·회고 질문을 펼쳐 볼 수 있게 했다.
- Gemini 결과와 분리해 로컬 규칙 해석임을 표시했다. 로컬 출력은 기존 사주 계산값에서 동기적으로 구성되며 별도 API 요청이 없다. Gemini 요청은 기존 명시적 동의 후 별도 실행한다.
- 저장된 계산 자료에서 로컬 해석을 재구성한다.
- `npm run check`: 타입 검사 및 테스트 49개 통과. 비구현 서브에이전트가 대운별 기간 연결 테스트를 추가하고 실행했다.
- `npm run build`: 통과 (`NODE_OPTIONS=--max-old-space-size=4096`).
- 브라우저 화면에서 저장된 계산 결과 복원 후 로컬 전체 해석과 대운별 펼치기 항목이 나타나는 것을 확인했다. 참가자 확인 전.
