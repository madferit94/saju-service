# 도령의 사주 한줄평

## 요청
- 사주를 계산한 직후 결과 맨 앞에 전체를 읽는 짧은 한줄평을 보여준다.
- 차분한 사주 전문가 도령의 말투를 사용한다.

## 구현 기준
- 일간, 월지의 오행, 월간과 일간의 십성 관계를 계산해 문장을 만든다. 같은 입력에는 같은 문장을 보인다.
- 한 문장은 길게 늘어놓지 않고, 강점과 살필 방향을 함께 담는다.
- 실제 전문가 경력, 맞힌 사건, 확정된 미래, 최종 용신을 주장하지 않는다.
- 기존 브라우저·계정 저장 형식은 바꾸지 않고 저장된 원국에서도 다시 계산한다.
- 한줄평 아래에 사용한 사주 글자를 짧게 표시해 근거를 확인할 수 있게 한다.

## 검증
- 서로 다른 원국에서 문장과 근거가 다르게 생성되는지 확인한다.
- 결과 화면과 기존 저장본 렌더링, 모바일 가독성, 전체 테스트와 빌드를 확인한다.

## 상태
- 구현 완료. 자동 검사 199개와 타입 검사·빌드 통과. 로컬 브라우저의 저장된 사주 결과에서 표시 확인. 모바일 화면과 참가자 직접 확인 전.
