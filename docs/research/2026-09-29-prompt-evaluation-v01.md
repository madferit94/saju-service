# 사주 풀이 프롬프트 적용과 품질 비교 v01

기록일: 2026-09-29. 모든 실제 생성 시험에는 가상 출생 정보만 사용했다.

## 적용 범위

- 선택형 Gemini 종합 해석의 지시문을 쉬운 말과 계산 근거 중심으로 바꿨다. 원국·대운·세운·월운은 기존 계산 코드가 만든 자료를 전달한다.
- 모델의 결과는 기존 JSON 형식과 계산 근거 검증을 거친다. 종합 풀이의 첫 문장이 한자·전문어로 시작하면 다시 쓰도록 한다.
- 기본 화면의 생활 운은 코드가 직접 쓰므로 이번 프롬프트 변경 대상이 아니다. 기존에 저장한 풀이도 자동으로 바뀌지 않는다.

## 실제 생성 비교

| 가상 사례 | 종전 지시 | 새 지시 | 확인한 점 |
|---|---|---|---|
| 성인, 1994-12-01 08:37 서울 | 약 17.5초, 첫 문장에 추상적인 표현 | 최종 시험 약 13.2초, 생활 행동으로 시작 | 새 지시에서 12개월·11개 대운 생성, API 성공 |
| 미성년, 2011-07-12 16:40 서울 | 비교 미실시 | 최종 시험 약 10.8초, 학습 행동으로 시작 | 새 지시에서 12개월·11개 대운 생성, API 성공 |

응답 시간은 각 조건을 한두 번만 재서 속도 향상의 증거가 아니다. 미성년 사례의 초기 생성물은 전문어로 시작했다. 모든 항목의 앞 두 문장을 강제로 검사하자 두 차례 생성이 모두 실패해 API가 502를 반환했다. 따라서 첫 종합 문장만 자동 차단하고, 나머지는 지시와 사람 평가로 개선하도록 조정했다. 이 과정은 새 지시가 모든 문장을 쉬운 말로 만든다는 보장이 없음을 보여 준다.

검증: 독립 작성 테스트를 포함한 전체 212개 테스트, 타입 검사, 배포용 빌드 통과. 실제 사용자 입력과 화면에서의 확인은 남아 있다.

## 결과의 성능을 높이는 다음 순서

1. **계산 정확도**: 절기 경계, 윤달, 시간대, 자정 무렵, 대운 시작 시점의 가상 사례를 고정한다. 독립적인 만세력 또는 전문가 확인값과 원국·시기를 대조한다. 프롬프트는 계산 오류를 고칠 수 없다.
2. **근거 일치**: 생성 문장마다 사용한 원국·대운·세운·월운의 근거를 데이터 항목으로 연결한다. 코드가 간지·연도·시기와 제공되지 않은 사실을 검사한다. JSON 모양만 맞는 것으로는 내용의 정확성이 보장되지 않는다.
3. **읽기 쉬움**: 서로 다른 가상 사주 6~10건부터 종전·새 지시를 같은 조건에서 여러 번 생성한다. 일반 독자가 이해한 비율, 잘못된 사실 수, 반복 문장 수를 같은 평가표로 기록한다. 미성년 사례를 반드시 포함한다.
4. **기본 결과 문장**: 생활 운처럼 코드가 직접 쓰는 문장을 따로 고친다. 어려운 전문어를 쉬운 생활 문장 뒤의 짧은 근거로 옮기면 AI 사용 여부와 관계없이 읽기 편해진다.
5. **속도와 비용**: 위 비교에서 요청 시간과 입력·출력 사용량을 함께 기록한다. 품질 기준을 통과한 후보끼리만 속도와 비용을 비교한다.
